# ตรวจไลน์อัพ {agent_th} ({agent}) ทีละรูป — คู่มือสำหรับผู้ดูรูป

คุณดูรูปไลน์อัพของ {agent_th} (VALORANT) ทีละใบด้วยตาจริง แล้วบอกว่า **ยืนตรงไหน · สกิลไปตกตรงไหน · เก็บหรือตัด**
ต้องใช้ Read เปิดรูปทุกใบ ห้ามเดาจากชื่อไฟล์อย่างเดียว

## ไฟล์ที่ได้ (อยู่โฟลเดอร์เดียวกับไฟล์นี้)
- `input-<ชุด>.json`: มี `map`, `side`, `zones` (ชื่อจุดโซนที่มีพิกัด) และ `images`
  - แต่ละใบใน `images` มี `rel`, `path` (เปิดด้วย Read), โฟลเดอร์ปัจจุบัน และข้อมูลจากเว็บ `web_*`
  - ข้อมูลเว็บชื่อโซนอาจผิดได้ แต่ **`web_ability` เชื่อได้**
- `map-<แมพ>.png`: แผนที่อ้างอิงของโปรแกรม
  - เส้นตารางทุก 0.05 (เส้นเข้มทุก 0.1 พร้อมตัวเลข) · จุดแดง = ชื่อโซน
  - **พิกัดที่ตอบต้องเป็นพิกัดบนรูปนี้**: x ซ้าย→ขวา 0–1, y บน→ล่าง 0–1

## รูปไลน์อัพหนึ่งใบ = หลายขั้นต่อกัน (มีเลข ①②③ กำกับ)
- **ขั้นแรก = จุดยืน**
  - มุมซ้ายบนมีมินิแมพ จุด/ลูกศรของผู้เล่นคือตำแหน่งยืน
  - ใกล้มินิแมพมี **ชื่อโซนที่ยืน** เป็นตัวหนังสือเล็ก เช่น "A Lobby" (บางคลิปเป็นภาษาอื่น เช่นรัสเซีย ให้แปลเทียบ)
  - **มินิแมพในเกมอาจหมุนคนละทางกับ map-<แมพ>.png** ให้เทียบรูปทรงแมพ ตัวอักษร A/B/C และชื่อโซนก่อนแปลงพิกัด
- **ขั้นกลาง = เล็ง/ท่า:** กระโดด, วิ่ง, คลิกซ้าย/ขวา
- **ขั้นสุดท้าย = จุดที่สกิลตก**
  - ระบุจากฉากในเกมว่าตกตรงไหน (มุม/กล่อง/ทางเข้า) แล้วแปลงเป็นพิกัดบนแผนที่อ้างอิง
  - บนมินิแมพของขั้นสุดท้ายมักเห็นวง/ไอคอนสกิลด้วย
- **สกิล: ใช้ตาม `web_ability` เสมอ** เอฟเฟกต์ของตัวละครเดียวกันมักสีเดียวกันหมด ดูจากรูปแยกพลาดง่าย

## ตรวจพิกัดก่อนตอบทุกใบ
- เปิด `map-<แมพ>.png` เทียบทุกครั้ง: **พิกัดต้องตกบนพื้นที่เดินได้** (สีเทา/เขียวมะกอก) ไม่ใช่ช่องว่างสีขาว
- **ถ้าสกิลตกในไซต์ ต้องอยู่ในกรอบสีเขียวมะกอกของไซต์นั้น**
  - "back site" = ฝั่งไกลจากทางที่ฝ่ายบุกเข้ามา
  - "default/plant" = กลางไซต์
  - วางให้ตรงมุมที่เห็นในฉาก
- ถ้าจุดตกกับชื่อ `target_zone` ที่เลือกห่างกันเกิน ~0.08 ให้ถามตัวเองว่าวางผิดหรือเลือกชื่อผิด
- เคยพลาดมาแล้ว: มินิแมพหมุน (B ซ้าย A ขวา) แล้วแปลงกลับด้าน จนจุดตกไปอยู่อีกฝั่งของไซต์

## ต้องตอบ: เขียน JSON list ลง `out-<ชุด>.json` (ใบละ 1 object ครบทุกใบใน input)
```json
{{"rel": "<ตาม input>",
 "stand_zone": "<ชื่อจาก zones ที่ใกล้จุดยืนที่สุด>", "stand_xy": [x, y], "stand_conf": "high|mid|low",
 "target_zone": "<ชื่อจาก zones ที่ใกล้จุดตกที่สุด>", "target_xy": [x, y], "target_conf": "high|mid|low",
 "target_desc": "<จุดตกแบบคนเล่นเรียก เช่น Heaven, Generator, Default plant — ภาษาอังกฤษสั้นๆ>",
 "side": "attack|defense", "site": "A|B|C|MID",
 "ability": "<แท็กตาม web_ability: {ability_tags}>",
 "steps": <จำนวนขั้นในรูป>, "technique": "none|jump|run|crouch|jump+run",
 "verdict": "keep|drop", "reason": "<ภาษาไทยสั้นๆ ทำไมตัด / จุดเด่นถ้าเก็บ>",
 "duplicate_of": "<rel ของใบที่เก็บไว้แทน ถ้าตัดเพราะซ้ำ ไม่งั้น null>",
 "name": "<ยืน> → <จุดตก> (<สกิลไทย>)"}}
```
- `side` = ฝั่งที่ไลน์อัพนี้ใช้จริง · `site` = ไซต์ที่เกี่ยวข้อง (ตกกลางแมพ = MID)
- ชื่อสกิลภาษาไทย: {ability_th}

## ตัดเมื่อ
- **ซ้ำ** กับอีกใบในชุดเดียวกัน = ยืนจุดเดียวกัน (ห่าง < ~0.03) + ตกจุดเดียวกัน (ห่าง < ~0.04) + `web_ability` เดียวกัน
  - เก็บใบที่ขั้นน้อยกว่า / ไม่ต้องกระโดดวิ่ง / รูปชัดไม่รก
  - ใส่ `duplicate_of` ชี้ใบที่เก็บ (ใบที่ถูกชี้ต้องเป็น keep)
- รูปพัง อ่านไม่ออก ไม่ใช่ {agent_th} ไม่ใช่แมพนี้ หรือเป็นรูปรวมหลายตัวละคร

ไม่ต้องตัดเพราะ "มีเยอะ" — ถ้าไม่ซ้ำให้เก็บ

## ห้าม
- ห้ามแก้/ย้าย/ลบไฟล์ใดๆ นอกจากเขียน `out-<ชุด>.json`
- ห้ามข้ามรูป ต้องครบทุกใบใน input
