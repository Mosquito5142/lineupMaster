# ตั้งเซิร์ฟเวอร์คอมมูนิตี้ (ทำครั้งเดียว ~15 นาที)

ใช้ **Supabase** เป็นที่เก็บกลาง (ฟรี) และ **Discord** เป็นทางล็อกอิน ทำตามทีละขั้น
ขั้นที่ต้องสมัคร/กรอกรหัส Claude ทำแทนไม่ได้ ถ้าติดตรงไหนถาม Claude ได้เลย

## 1. สร้างโปรเจกต์ Supabase
1. เข้า <https://supabase.com> → **Start your project** → สมัครด้วย GitHub หรืออีเมล
2. **New project**
   - Name: `lineupmaster`
   - Database Password: กด Generate แล้วเก็บไว้ (ไม่ต้องใช้กับโปรแกรม)
   - Region: **Southeast Asia (Singapore)** (ใกล้ไทยสุด)
3. รอสร้างเสร็จ (~2 นาที)

## 2. สร้างตาราง
1. เมนูซ้าย **SQL Editor** → **New query**
2. เปิดไฟล์ `docs/community/schema.sql` ในโปรเจกต์นี้ ก๊อปทั้งไฟล์มาวาง → **Run**
3. ขึ้น `Success. No rows returned` = เสร็จ (รันซ้ำได้ ไม่พัง)

## 3. สร้างแอป Discord สำหรับล็อกอิน
1. เข้า <https://discord.com/developers/applications> → **New Application** → ตั้งชื่อ `LineupMaster` → Create
2. เมนูซ้าย **OAuth2**
   - ก๊อป **Client ID** เก็บไว้
   - กด **Reset Secret** → ก๊อป **Client Secret** เก็บไว้ (โชว์ครั้งเดียว — **ห้ามส่งให้ใคร รวมถึงห้ามวางในแชท**)
   - **Redirects** → Add Redirect → ใส่ `https://<รหัสโปรเจกต์>.supabase.co/auth/v1/callback`
     (ดูที่อยู่ที่ถูกได้จากขั้น 4 ข้อ 2 — Supabase โชว์ Callback URL ให้ก๊อป) → **Save Changes**

## 4. เปิดล็อกอิน Discord ใน Supabase
1. Supabase → **Authentication** → **Sign In / Providers** (หรือ Providers) → **Discord**
2. เปิด **Enable** → วาง Client ID + Client Secret จากขั้น 3 → **Save**
   (ตรงนี้มี **Callback URL** ให้ก๊อปไปใส่ใน Discord ขั้น 3)
3. **Authentication** → **URL Configuration** → **Redirect URLs** → Add URL ใส่:
   - `http://127.0.0.1:*/**`
   - ถ้าระบบไม่รับ `*` ตรงพอร์ต ให้ใส่ `http://127.0.0.1:8760/**` แทน (พอร์ตที่หน้าเว็บใช้ปกติ)

## 5. ใส่ในโปรแกรม
1. Supabase → **Project Settings** → **API** (หรือ **Data API** / **API Keys**)
   - ก๊อป **Project URL** (`https://xxxx.supabase.co`)
   - ก๊อป **anon public** key (ขึ้นต้น `eyJ...`) — ตัวนี้ไม่ใช่ความลับ ใส่ในโปรแกรมแจกเพื่อนได้
   - **ห้ามใช้ `service_role` key** (ตัวนั้นเป็นความลับ ข้ามสิทธิ์ทุกอย่าง)
2. เปิด **จัดการคลังไลน์อัพ (เว็บ)** → แท็บ **คอมมูนิตี้** → วาง URL + anon key → **บันทึก**
3. กด **ล็อกอินด้วย Discord** → กดยืนยันในหน้า Discord → เด้งกลับมาเห็นชื่อเรา = ใช้ได้

## 6. แจกเพื่อน
1. ปิด LineupMaster ทุกตัวก่อน แล้วรัน (หรือบอก Claude ให้ทำ):

   ```
   python tools/build_exe.py --release
   ```

2. ได้ `dist/LineupMaster-แจกเพื่อน.zip`
   - มีตัวโปรแกรม + ชื่อโซนของแมพ + ที่อยู่เซิร์ฟเวอร์ (เพื่อนไม่ต้องกรอกเอง)
   - **ไม่มี**คลังรูป หมุด การล็อกอิน หรือค่าที่ตั้งบนเครื่องเรา
3. เพื่อนแตก zip → ดับเบิลคลิก `จัดการคลังไลน์อัพ (เว็บ).bat` → แท็บคอมมูนิตี้ → ล็อกอิน Discord → เอาไลน์อัพเข้าคลัง
4. เพื่อนต้องตั้งกรอบแคปชื่อโซนของเขาเองครั้งแรก (`เลือกกรอบแคปชื่อโซน.bat`) ถ้าจะใช้ F9 และตั้งจอใน `config.yaml` (`display.monitor`)

## ใช้งาน
- **แชร์:** แท็บคลัง → เลือกใบ → **⇪ แชร์ขึ้นคอมมูนิตี้** (หรือ Ctrl+คลิกหลายใบ → ปุ่มในแถบล่าง)
  - ต้องปักหมุดจุดยืนแล้ว
  - ใบที่ดึงมาจากเว็บไลน์อัพอื่น (หน้า "หาไลน์อัพจากเว็บ") แชร์ไม่ได้ — ไม่ใช่รูปของเรา
- **ให้คะแนน:** ในเกม **F7** = ใช้ได้จริง · **F8** = แจ้งผิด (ใช้ไม่ได้) กับใบที่เอามาจากคอมมูนิตี้
  คะแนนส่งขึ้นเซิร์ฟเวอร์ตอนเปิดแท็บคอมมูนิตี้ · หรือกด ✓/✗ ในแท็บคอมมูนิตี้ตรงๆ
- ป้ายชื่อรูปในเกมโชว์ `✓12 ✗1` = คะแนนของทุกคน (อัปเดตทุกครั้งที่เปิดแท็บคอมมูนิตี้)
