# LineupMaster

ผู้ช่วยเปิดรูปไลน์อัพ VALORANT บนจอที่สอง **ควบคุมด้วยแป้น Numpad** —
กดปุ่มเดียวได้รูปที่ต้องการ ไม่ต้องละมือจากเกม ไม่ต้องออกจากหน้าเกม

- **กดปุ่ม = ได้สิ่งนั้น 100% ทุกครั้ง** ไม่มีการฟังเสียง ไม่มีการเดา
- **1 ไลน์อัพ = 1 รูป** เอารูปที่ดูแล้วเข้าใจครบในภาพเดียวมาวางไว้
- **จอ 2 มีแค่รูป** กับแถบบอกสถานะบางๆ ด้านบน

## เริ่มจากศูนย์ (โคลน/ดึงโค้ดมาใหม่)

**`lineups/` (รูปไลน์อัพ) ไม่ได้อยู่ใน git** — หนักและเป็นสื่อ เก็บแยกไว้ที่ Google Drive
ต่างหาก (ดูเหตุผลใน `.gitignore`) โคลนโค้ดมาอย่างเดียวจะยังไม่มีรูปให้ดู ต้องทำ 4 ขั้นนี้ก่อน:

1. **ติดตั้ง**

   ```bash
   setup.bat
   ```

   ดับเบิลคลิกก็ได้ — หา Python ในเครื่อง สร้าง `.venv` แล้วลงแพ็กเกจให้ (รายละเอียดอยู่หัวข้อ
   [ย้ายไปเครื่องอื่น](#ย้ายไปเครื่องอื่น) ด้านล่าง)

   > **ต้องมี Python 3.12 ในเครื่อง** (3.8-3.12 ก็ได้ แต่แนะนำ 3.12) — ฟีเจอร์ "อ่านชื่อโซน
   > ด้วย OCR" (ดูหัวข้อ [ป้ายชื่อโซน](#ป้ายชื่อโซน-เทียบกับที่เกมบอกบนจอ)) ใช้แพ็กเกจ
   > `winsdk` ซึ่งยังไม่มีไฟล์สำเร็จรูปให้ Python 3.13/3.14 — `setup.bat` จะลองหา `py -3.12`
   > ก่อนเสมอ ถ้าไม่มีจะใช้ Python เวอร์ชันอื่นแทนแต่เตือนไว้ (ส่วนอื่นของโปรแกรมยังใช้ได้ปกติ
   > แค่ปุ่มอ่านชื่อโซนจะใช้ไม่ได้)

2. **บิ้วโปรแกรม**

   ```bash
   .venv\Scripts\python.exe tools\build_exe.py
   ```

   ได้ `dist\LineupMaster\LineupMaster.exe` พร้อม shortcut ของเครื่องมือย่อยทั้งหมด — **ใช้
   `dist\LineupMaster\` เป็นตัวหลักจากนี้ไป** (ดูหัวข้อ [บิ้วเป็น exe](#บิ้วเป็น-exe-เครื่องปลายทางไม่ต้องมี-python))

   หมุดบนแผนที่ (`positions.json`), ป้ายชื่อโซน (`callouts.json`), สกิล/ไม้ตาย/แท็ก
   (`meta.json`) ที่เคยทำไว้ **มากับ git อยู่แล้วและอยู่ที่ `dist\LineupMaster\` พอดีตั้งแต่
   ขั้นตอนนี้เลย ไม่ต้องย้ายไฟล์เอง** (156 หมุด, ชื่อโซนวางตำแหน่งไว้แล้ว 295/300, สกิลติดไว้
   ครบ) — เหตุผลที่มันมาอยู่ตรงนี้ได้เองคือ git track ไฟล์ 4 อันนี้จากตำแหน่งใน
   `dist/LineupMaster/` โดยตรง (ดู `.gitignore`)

3. **ดึงรูปไลน์อัพจาก Google Drive**

   โหลดโฟลเดอร์ `lineups/` จาก Google Drive มาวางไว้ **ข้างๆ `LineupMaster.exe`** ให้ได้
   โครงสร้างแบบนี้:

   ```
   dist/LineupMaster/
   ├── LineupMaster.exe
   ├── lineups/          <- เอามาวางตรงนี้
   │   ├── ascent/...
   │   └── ...
   ├── positions.json    <- มากับ git แล้วจากขั้นตอนก่อนหน้า
   └── ...
   ```

   ตรวจว่าวางถูกที่ไหม:

   ```bash
   dist\LineupMaster\LineupMaster.exe --list
   ```

   ควรเห็น `รวม N รูป` ท้ายผลลัพธ์ (ไม่ใช่ `ไม่เจอไลน์อัพเลยใน ...`)

4. **เปิดโปรแกรม**

   เปิด `dist\LineupMaster\LineupMaster.exe` หรือ shortcut ที่บิ้วให้เอง (เช่น
   `จัดการคลังไลน์อัพ.lnk`)

รูปแผนที่ (`assets/maps/`) กับรูปอ้างอิงชื่อโซน (`assets/callout_reference/`) ก็มากับ git
เหมือนกัน (อยู่ที่ root ของโปรเจกต์ ไม่ใช่ใน `dist/`) ขั้นตอนบิ้วจะก๊อปเข้า
`dist\LineupMaster\assets\` ให้เองอัตโนมัติ ไม่ต้องรัน `fetch_maps.py` /
`fetch_callout_reference.py` เอง เว้นแต่อยากได้เวอร์ชันใหม่กว่า (ดูหัวข้อ
[หน้าแผนที่](#หน้าแผนที่-ชั้น-0))

ส่วน `last-view.json` (แมพ/ฝั่งล่าสุด + สถิติใช้บ่อย) ไม่ได้มากับ git — เป็นแค่สถิติส่วนตัว
เปิดโปรแกรมครั้งแรกจะสร้างไฟล์ใหม่เองอัตโนมัติ ไม่ต้องทำอะไร

> **อยากรันจากซอร์สตรงๆ ด้วย `run.bat` แทนการบิ้ว exe?** ทำได้ แต่ `run.bat` อ่านข้อมูลจาก
> root ของโปรเจกต์ ไม่ใช่จาก `dist/LineupMaster/` — ต้องก๊อป
> `dist\LineupMaster\{positions,callouts,meta,capture}.json` มาวางที่ root เองก่อน ไม่งั้น
> จะเห็นคลังว่างเปล่า (ไม่มีหมุด/ชื่อโซน/แท็กเลย) เพราะไฟล์ที่ root ไม่ได้ตามมากับ git อีกต่อไป

## ทำไมถึงไม่ใช่โปร

โปรแกรมนี้ **ไม่แตะเกมเลยแม้แต่นิดเดียว**:

- ไม่อ่าน/เขียน memory ของเกม, ไม่ inject DLL, ไม่ hook process เกม
- **ไม่ส่ง input เข้าเกม** — ไม่มี macro, ไม่มี auto-aim, ไม่ขยับเมาส์ให้
- ไม่มี overlay ทับหน้าต่างเกม (เป็นหน้าต่างแยกบนอีกจอ)
- ไม่แคปหน้าจอเกมไปวิเคราะห์, ไม่อ่านไฟล์/log ของเกม
- ดักปุ่มด้วย hook ระดับ OS แบบ **อ่านอย่างเดียว ไม่ suppress** — กลไกเดียวกับ
  Discord push-to-talk, OBS, Steam overlay ที่ใช้กันปกติ

## ปุ่มควบคุม

> **ต้องเปิด NumLock ไว้** ไม่งั้น Windows จะส่ง Numpad เป็นปุ่มลูกศร/End/PgDn แทน
> VALORANT ไม่ได้ผูก Numpad ไว้เลย จึงไม่ชนกับปุ่มในเกม
> (โปรแกรมแยก Numpad ออกจากแป้นเลขแถวบนด้วย virtual key code — กดเปลี่ยนอาวุธ 1-4
> จึงไม่ไปสั่งโปรแกรม)

| ปุ่ม | ทำอะไร | ต้องกดบ่อยแค่ไหน |
|---|---|---|
| **Numpad +** / **−** | เปลี่ยนแมพ (วนเฉพาะแมพที่มีรูป) | ครั้งเดียวต่อเกม — และจำไว้ข้ามการปิดโปรแกรม |
| **Numpad 0** | สลับ บุก ↔ ตั้งรับ | ครั้งเดียวต่อครึ่ง |
| **Numpad 1 / 2 / 3** | ดูเฉพาะจุด A / B / C (กดซ้ำ = กลับไปดูทั้งครึ่ง) | ตามใจ |
| **Numpad .** | กลับไปดูทั้งครึ่ง | |
| **Numpad 4 / 6** | เลื่อนกรอบเลือกรูป | |
| **Numpad 5** | ซูมรูปที่เลือกเต็มจอ (กดซ้ำ = ออก) | |
| **Numpad \*** | เล่น/หยุด gif ของรูปที่ซูมอยู่ (ต้องกดซูมก่อน) | |
| **Numpad /** | เข้า/ออกหน้าแผนที่ — เลือกจาก "จุดที่เรายืน" | ตอนไม่รู้ว่ามีสูตรอะไรตรงนี้บ้าง |
| **Numpad 1-9** | *(เฉพาะบนแผนที่)* เลือกหมุดเลขนั้น · กดเลขเดิมซ้ำ = เข้าไปดูรูป | |
| **Insert** | แคปชื่อโซนจากจอเกมเอง แล้วชี้หมุดที่ใกล้ที่สุด ([รายละเอียด](#หาหมุดจากชื่อโซนอัตโนมัติ-ocr)) | ตอนไม่แน่ใจว่ายืนตรงไหนบนแผนที่ |
| **Delete** | สลับตัวละคร (ทั้งหมด → โซวา → ไซเฟอร์ → …) ([รายละเอียด](#ตัวกรอง-เล่นหลายตัวละครหลายสกิล)) | ครั้งเดียวตอนเปลี่ยนตัวที่เล่น |
| **Home** | สลับสกิล (ทั้งหมด → รีคอน → ช็อก → …) | ตามสถานการณ์ |
| **End** | เปิด/ปิด "เฉพาะไม้ตาย" ⭐ | ตอนอยากดูแค่ท่าที่ใช้จริง |
| **Page Up** | สลับแท็กสถานการณ์ (แก้ทางตัวไหน / post-plant) | ตอนรู้ว่าศัตรูมีตัวไหน |
| **Page Down** | โหมดซ้อม: สุ่มไลน์อัพจากที่กรองอยู่ แล้วซูมให้เลย | ตอนซ้อมในห้องคัสตอม |
| **ลากตรงไหนก็ได้** | ย้ายหน้าต่างไปอีกจอ | |
| **F11** / ดับเบิลคลิก | สลับเต็มจอจริง | |
| **Esc** | ปิดโปรแกรม | |

เปลี่ยนปุ่มได้ใน `config.yaml` → `hotkeys`

## ตัวกรอง (เล่นหลายตัวละคร/หลายสกิล)

พอคลังโตขึ้นและเริ่มเล่นหลายตัว การเห็นทุกอย่างพร้อมกันกลับช้ากว่า — **บล็อก 6 ปุ่มเหนือลูกศร**
(ติดกับ numpad มือเดียวกดถึง) จึงเป็นชุดตัวกรอง:

| ปุ่ม | กรองอะไร |
|---|---|
| **Delete** | ตัวละคร — เล่นไซเฟอร์อยู่ก็ไม่ต้องเห็นของโซวา |
| **Home** | สกิล — รีคอนกับช็อกใช้คนละสถานการณ์สิ้นเชิง |
| **End** | ⭐ ไม้ตาย — เฉพาะท่าที่ติดดาวไว้ว่าใช้จริง |
| **Page Up** | สถานการณ์ — `anti-cypher`, `post-plant` ฯลฯ |

- **กรองแล้วมีผลทุกที่พร้อมกัน** — ทั้งกริดรูป, **หมุดบนหน้าแผนที่**, ปุ่มจุด A/B/C และปุ่ม
  **Insert** (OCR) ใช้ตัวตัดสินตัวเดียวกัน จึงไม่มีทางที่กริดกับแผนที่จะไม่ตรงกัน
- **หัวจอบอกเสมอว่ากรองอะไรอยู่** (`กรอง: ไซเฟอร์ · กับดัก · ⭐`) — กันเปิดกรองค้างแล้วนึกว่ารูปหาย
- **วนเฉพาะค่าที่มีจริง** ของแมพ/ฝั่งนั้น ไม่ต้องกดผ่านตัวเลือกว่างๆ
- ตัวละคร/สกิล **จำข้ามการปิดโปรแกรม** (เล่นตัวเดิมข้ามวัน) ส่วน ⭐ กับแท็กสถานการณ์
  **ไม่จำ** เพราะเป็นตัวกรองเฉพาะกิจ เปิดค้างข้ามวันแล้วจะงง

### โหมดซ้อม (Page Down)

กดแล้วสุ่มไลน์อัพจากชุดที่กรองอยู่มาซูมให้เลย — เปิดคู่กับห้องคัสตอมแล้วไล่ยิงตามได้เรื่อยๆ
**สุ่มจากใบที่ซ้อมน้อยที่สุดก่อน** ไม่ใช่สุ่มล้วน (สุ่มล้วนจะวนเจอใบเดิมซ้ำๆ แล้วบางใบไม่เคยถูก
หยิบเลย) หัวจอบอกด้วยว่า `เคยซ้อมแล้ว 12/40 ใบ`

> นับแยกจากสถิติ "เปิดดูบ่อย" ที่ใช้จัดเรียงรูปในกริด — คนละความหมายกัน ถ้านับรวมกัน
> ลำดับรูปในกริดจะเพี้ยนเพราะการสุ่มซ้อม

### ติดแท็กยังไง

ทำในหน้า **จัดการคลังไลน์อัพ** แถว **"สกิล/แท็ก"**: เลือกสกิล · ติ๊ก ⭐ ไม้ตาย · พิมพ์แท็ก
คั่นด้วย `,` แล้วกด **บันทึกการแก้ไข**

- มีปุ่ม **"ตั้งสกิลนี้ให้ทุกใบที่กรองอยู่"** — กรองเป็นแมพ/ฝั่ง/จุดทางซ้ายก่อน แล้วเหมาทีเดียว
  (ไว้ติดสกิลย้อนหลังให้ของเก่าทั้งคลัง ไม่ต้องกดทีละใบเป็นร้อยครั้ง)
- แท็กเก็บใน **`meta.json`** คีย์ด้วยที่อยู่ของรูป — **ไม่ได้เก็บในชื่อไฟล์** เพราะดาวกับจำนวน
  ครั้งที่ซ้อมเปลี่ยนตลอดเวลา · เปลี่ยนชื่อ/ย้ายรูปแล้วแท็กตามไปเอง
- สกิลที่อ่านได้จากชื่อไฟล์อยู่แล้ว (เช่นตั้งชื่อว่า `recon_...`) ยังใช้ได้เหมือนเดิม —
  `meta.json` เป็นแค่ตัวเติมช่องที่ชื่อไฟล์ไม่ได้บอกไว้

## ดู 4 ชั้น กดเท่าที่อยากละเอียด

```
ชั้น 0  แผนที่               ← กด /        "ยืนตรงนี้ ยิงไปไหนได้บ้าง"
ชั้น 1  ทั้งครึ่ง (ทุกจุด)   ← ค่าเริ่มต้น  ระหว่างตาไม่ต้องกดอะไรเลย
ชั้น 2  เฉพาะจุดที่เลือก      ← กด 1/2/3    รูปใหญ่ขึ้น
ชั้น 3  รูปเดียวเต็มจอ        ← กด 5        ดูพิกัดชัดๆ  ／ กด * ดู gif วิถีลูก
```

ชั้น 0 ถามคนละคำถามกับอีก 3 ชั้น: อีก 3 ชั้นเรียงตาม **จุดเป้าหมาย** (มาจากโฟลเดอร์)
ส่วนชั้นแผนที่เรียงตาม **จุดที่เรายืน** — ดูวิธีทำที่หัวข้อ "หน้าแผนที่" ข้างล่าง

แถบบนหัวจอบอกตลอดว่าอยู่ไหน:

```
HAVEN   │   ตั้งรับ   │   A [B] C   │   3 รูป
```

`[B]` = กำลังดูจุด B · `·` แทนตัวอักษร = จุดนั้นยังไม่มีรูป

## จัดการคลัง (เพิ่ม / ลบ / เปลี่ยนชื่อ / ย้าย)

```bash
python tools/manage.py
```

หน้าต่างเดียวจบ — ซ้ายเป็นรูปย่อทั้งคลัง (กรองตามแมพ/ฝั่ง/จุด + ค้นหาจากชื่อ)
ขวาเป็นรูปใหญ่กับช่องแก้ไข

| ทำอะไร | ยังไง |
|---|---|
| **เพิ่ม** | ลากไฟล์มาวาง · **Ctrl+V** วางจากคลิปบอร์ด · ปุ่ม **+ เพิ่มรูป...** |
| **เปลี่ยนชื่อ / ย้าย / แก้โน้ต** | แก้ช่องในฟอร์ม แล้วกด **บันทึกการแก้ไข** (ทำพร้อมกันได้ในคลิกเดียว) |
| **ลบ** | ปุ่ม **ลบ** หรือกด **Delete** — มีถามยืนยันก่อน |
| **จิ้มหมุด / ตั้งป้าย A-B-C** | แผนที่อยู่ข้างรูปพรีวิวเลย ไม่ต้องเปิด `pin_lineups.py` แยก (ดูวิธีจิ้มที่หัวข้อ [หน้าแผนที่](#หน้าแผนที่-ชั้น-0)) |
| **ซูมดูรูป** | **หมุนลูกกลิ้งบนรูป** (ซูมอยู่ในกรอบเดิม ไม่เด้งหน้าต่างใหม่) · ลาก = เลื่อนดู · ดับเบิลคลิก = กลับไปพอดีกรอบ |
| **ติดสกิล / ⭐ / แท็ก** | แถว **สกิล/แท็ก** ในฟอร์ม — ใช้กรองตอนเล่น ([รายละเอียด](#ตัวกรอง-เล่นหลายตัวละครหลายสกิล)) · ปุ่มขวาสุดเหมาทั้งชุดที่กรองอยู่ |
| **หมุนแผนที่** | แถบเลื่อนใต้แผนที่ — ปรับได้ทีละ 1° ตั้งแต่ 0-359 · ปุ่ม **⟳ 90°** กดทีละ 90 · ปุ่ม **รีเซ็ต** กลับ 0 |

- แคปจอด้วย **Win+Shift+S** แล้ว **Ctrl+V** ได้เลย ไม่ต้องเซฟไฟล์ก่อน
- **หมุนลูกกลิ้งบนรูปเพื่อซูม** — ซูมอยู่ในกรอบเดิม ไม่เด้งหน้าต่างใหม่ จะได้เพ่งดูว่าในรูปยืน
  ตรงไหน/เล็งไปทางไหน แล้วคลิกแผนที่ข้างๆ ได้เลยโดยไม่ต้องปิดอะไรก่อน
  (ใช้ได้เหมือนกันในหน้าจิ้มหมุดและหน้าวางตำแหน่งชื่อโซน)
- **เส้นแบ่งลากได้ทั้งสองเส้น** — ระหว่างรายการรูปย่อกับแผงขวา และระหว่างรูปกับแผนที่ —
  ลากให้ฝั่งที่กำลังใช้งานใหญ่ขึ้นได้ตามใจ
- **แถบหมุนแผนที่** — รูปแมพที่เอามาเทียบจากที่อื่น (คลิปสอน เว็บอื่น) มักหันคนละทางและหมุนมา
  เป็นองศาไม่ลงตัว เลื่อนแถบให้หันเหมือนกันก่อนแล้วค่อยจิ้มหมุดจะเทียบง่ายกว่ามาก
  **หมุนแค่ภาพที่เห็น พิกัดที่เซฟไม่ขยับตาม** — หมุด ป้าย A/B/C และชื่อโซนหมุนตามภาพไปด้วย
  คลิกจิ้มหมุดตอนหมุนอยู่ก็ยังลงตำแหน่งถูก (โปรแกรมแปลงพิกัดกลับให้เอง) · จำมุมแยกต่อแมพ
  สลับรูปในแมพเดิมไม่ต้องตั้งใหม่
- **ลบ = ย้ายเข้า `.trash/`** ที่รากโปรเจกต์ ไม่ได้ลบถาวร ลากกลับมาเองได้
  (`.trash/` อยู่นอก `lineups/` ตัวสแกนจึงมองไม่เห็น)
- ชื่อซ้ำจะต่อท้ายเป็น `(2)` ให้เอง ไม่ทับของเดิม
- **ช่องโน้ต** — พิมพ์คำอธิบายสั้นๆ (เช่น "ชาร์จ 2 ขีด เด้ง 1") แล้วมันจะ**โชว์แทนชื่อไฟล์**บน
  จอที่สองเลย มีประโยชน์มากตอนสูตรจากจุดยืนเดียวกันเยอะๆ เพราะรูปจะหน้าตาคล้ายกันจนแยกจาก
  ชื่อไฟล์อย่างเดียวยาก — ลบข้อความในช่องจนว่างแล้วบันทึก จะกลับไปโชว์ชื่อไฟล์เหมือนเดิม

> **สำคัญ: อย่าย้าย/เปลี่ยนชื่อไฟล์เองใน File Explorer**
> ไลน์อัพหนึ่งตัวมีของพ่วงที่ผูกกับชื่อและที่อยู่อีก 4 อย่าง — ไฟล์ `.gif`, ไฟล์โน้ต `.txt`,
> หมุดใน `positions.json` และสถิติ `uses` ใน `last-view.json` โปรแกรมจัดการลากตามให้ครบ
> แต่ถ้าย้ายเองหมุดกับสถิติที่สะสมไว้จะหลุดหายเงียบๆ
>
> และควร **ปิดโปรแกรมหลักก่อนแก้ไข** เพราะมันเขียน `last-view.json` ทุกครั้งที่กดปุ่ม

### อยากได้คลิปวิถีลูกด้วย (ไม่บังคับ)

วางไฟล์ `.gif` **ชื่อเดียวกับรูปนิ่ง** ไว้ในโฟลเดอร์เดียวกัน — หลักการเดียวกับไฟล์ `.txt`
ที่ใช้ใส่คำอธิบาย ไม่ต้องย้ายหรือเปลี่ยนชื่อรูปเดิม

```
lineups/haven/defense/sova/B/ทะลุควันทางเชื่อม.png   ← รูปนิ่ง โชว์ตามปกติทุกที่
lineups/haven/defense/sova/B/ทะลุควันทางเชื่อม.gif   ← กด Numpad * ตอนซูมถึงจะเล่น
```

- gif ที่จับคู่แล้ว **ไม่นับเป็นไลน์อัพใบใหม่** ในกริดยังเห็นรูปเดียวเหมือนเดิม
- gif **ไม่เล่นเอง** ต้องซูมแล้วกดเองเท่านั้น (จอ 2 มีไว้เหลือบตาแวบเดียว ภาพขยับจะแย่งสายตา)
- กดแล้ว **วนซ้ำไปเรื่อยๆ** จนกดซ้ำเพื่อหยุด หรือกด Numpad 5 ออกจากซูม
- ถ้าวาง `.gif` โดยไม่มีรูปนิ่งชื่อเดียวกัน มันจะกลายเป็นไลน์อัพปกติ 1 ใบ (กริดโชว์เฟรมแรก)
- **ควรยาวไม่เกิน 3 วินาที** — `--list` จะเตือนให้ถ้าเกิน (ปรับเกณฑ์ที่ `gif.max_seconds`
  ใน `config.yaml`) โปรแกรมไม่ตัดให้เอง ต้องไปตัดมาก่อน

- ชื่อแมพต้องตรงกับที่มีใน `aliases.yaml` (ascent, bind, haven, split, icebox,
  breeze, fracture, pearl, lotus, sunset, abyss, corrode, summit)
- วางรูปเพิ่มระหว่างเกมได้เลย ไม่ต้องรีสตาร์ต — สแกนใหม่ทุกครั้งที่กดปุ่ม
- โฟลเดอร์เปล่าไม่มีผลอะไร แมพที่ไม่มีรูปจะถูกข้ามตอนกดวน

ตรวจว่าโปรแกรมอ่านโฟลเดอร์ถูกไหม (บอกด้วยว่าใบไหนมี gif และยาวกี่วินาที):

```bash
.venv\Scripts\python.exe -m lineupmaster --list
```

## หน้าแผนที่ (ชั้น 0)

**เปิดโปรแกรมมาจะอยู่หน้านี้เลย** (เปลี่ยนได้ที่ `display: start_on_map` ใน `config.yaml`)
หรือกด **Numpad /** สลับเข้า/ออกเมื่อไหร่ก็ได้ — ได้แผนที่พร้อมหมุดจุดยืนที่มีเลขกำกับ:

```
ASCENT   │   ตั้งรับ   │   แผนที่   │   7 จุดยืน   │   ยังไม่จิ้ม 6 รูป
```

- **ทุกหมุดมีเส้นจางลากไปเป้าตลอดเวลา** เห็นได้เลยว่าแต่ละจุดยิงไปทางไหนโดยไม่ต้องกดเลือกก่อน
- **กดเลขหมุด** → หมุดนั้นสว่างเป็นสีเหลือง เส้นของมันเข้มขึ้นชัดกว่าเส้นจางของหมุดอื่น
- **กดเลขเดิมซ้ำ** → เข้าไปดูรูปของหมุดนั้น (กลับสู่ชั้น 1 แต่กรองเหลือเฉพาะสูตรจากจุดนั้น)
- **Numpad /** อีกที → ออกจากแผนที่ ล้างตัวกรอง กลับไปเห็นทั้งครึ่งตามเดิม
- `×3` ใต้หมุด = จุดนั้นมี 3 สูตร · หมุดเกิน 9 อันใช้ **Numpad .** เปลี่ยนหน้า
- **+/− และ 0 ยังเปลี่ยนแมพ/สลับฝั่งได้ตามปกติ** ขณะอยู่บนแผนที่
- ป้ายตัวอักษร **A/B/C สีฟ้า** กำกับจุดยิงให้เอง — รูปแผนที่ดิบไม่มีตัวอักษรนี้มาให้ (มีแค่สี
  แต้มบอกว่าเป็นห้องเฉยๆ) **เส้นประ+จาง** = ยังไม่มีใครตั้งเอง เดาจากค่าเฉลี่ยจุด "to" ของสูตร
  ในจุดนั้น (อาจเพี้ยนถ้าจุดที่คลิกตอนจิ้มแต่ละสูตรกระจายกันมาก) · **ทึบชัด** = ตั้งเองแล้วผ่าน
  ปุ่ม "ตั้งป้าย" ใน `tools/pin_lineups.py` (ดูหัวข้อล่าง) แม่นกว่าเพราะเป็นจุดที่ตั้งใจวางจริงๆ

### ตั้งค่าครั้งแรก (ทำ 2 ขั้น)

โฟลเดอร์บอกได้แค่ว่า *ยิงไปจุดไหน* ไม่ได้บอกว่า *เรายืนตรงไหน* ข้อมูลจุดยืนจึงต้องจิ้มเอง

```bash
python tools/fetch_maps.py
```

โหลดรูปแผนที่ทางการจาก valorant-api.com (ฟรี ไม่ต้องล็อกอิน) เก็บที่ `assets/maps/`

```bash
python tools/pin_lineups.py
python tools/pin_lineups.py --map ascent    # เปิดมาแล้วกรองแมพนี้ไว้ก่อน
```

**ซ้ายเป็นลิสต์รูปย่อทั้งคลัง** กรองตามแมพ/ฝั่ง/จุด + ค้นหาจากชื่อได้ — รูปที่จิ้มแล้วมี
`✓` นำหน้าชื่อ **เลือกรูปไหนก็ได้จากตรงนี้เพื่อไปจิ้ม** ไม่ต้องไล่ทีละรูปตามลำดับ
กลางเป็นรูปสูตร ขวาเป็นแผนที่ — **คลิกที่ 1 = จุดที่เรายืน · คลิกที่ 2 = จุดที่ลูกลง**
แล้วเด้งไปรูปถัดไปที่ยังไม่จิ้มเอง เซฟลง `positions.json` ทุกรูป (ปิดกลางคันไม่เสียงาน)

- คลิกใกล้หมุดฟ้าที่มีอยู่แล้ว = **สแนปเข้าหมุดเดิม** หลายสูตรที่ยืนจุดเดียวกันจะรวมเป็นหมุดเดียว
  (ควรทำ ไม่งั้นแมพเดียวจะมีหมุดเกิน 9 จนกดเลขเลือกไม่ครบ)
- **ตั้งผิดแก้ได้เสมอ**: เลือกรูปนั้นจากลิสต์ (เลิกติ๊ก "เฉพาะที่ยังไม่จิ้ม" ถ้ามันถูกซ่อนไปแล้ว)
  แล้วกด **ลบหมุดของรูปนี้** มุมขวาบน หรือกด `Delete` — ลบแค่พิกัดหมุด ไม่ได้ลบรูป จิ้มใหม่ได้ทันที
- `Space` ข้ามไปรูปถัดไปที่ยังไม่จิ้ม · `Backspace` ย้อน/ยกเลิกคลิกแรก · `Esc` ออก

**ตั้งป้าย A/B/C เอง (ถ้าค่าเฉลี่ยอัตโนมัติเพี้ยน)**: เหนือรูปสูตรมีปุ่ม **"ตั้งป้าย A"** /
**"ตั้งป้าย B"** ให้ตามจุดที่มีในแมพนั้น — กดปุ่ม แล้วคลิกตำแหน่งจริงบนแผนที่ 1 ที เป็นอัน
เสร็จ (กดปุ่มเดิมซ้ำ = ยกเลิกโหมดโดยไม่วาง) ป้ายจะเปลี่ยนจากเส้นประจางเป็นทึบชัดทันที
กด **"ล้าง"** ข้างปุ่มนั้นถ้าอยากกลับไปใช้ค่าเฉลี่ยอัตโนมัติ

**ตั้งครั้งเดียวใช้ได้ทั้งบุกและตั้งรับ** — จุด A/B/C อยู่ที่เดิมไม่ว่าจะฝั่งไหน ป้ายที่ตั้งเอง
จึงไม่ผูกกับฝั่ง ไม่ต้องตั้งซ้ำสองรอบ (ส่วนค่าเฉลี่ยอัตโนมัติที่ยังไม่ได้ตั้งเอง คำนวณแยกราย
ฝั่งอยู่ เพราะอิงจุด "to" ของสูตรฝั่งนั้นๆ)

**ไม่ต้องจิ้มให้ครบทีเดียว** รูปที่ยังไม่จิ้มใช้งานได้เหมือนเดิมทุกอย่าง แค่ไม่โผล่บนแผนที่
จิ้มเพิ่มระหว่างเปิดโปรแกรมอยู่ได้เลย ไม่ต้องรีสตาร์ต

> พิกัดหมุดเป็นสัดส่วนของรูปแผนที่ (0..1) ถ้าเปลี่ยนไปใช้รูปแผนที่คนละอัน หมุดจะเพี้ยนทั้งหมด

### ป้ายชื่อโซน (เทียบกับที่เกมบอกบนจอ)

VALORANT โชว์ชื่อโซนเองอยู่แล้วมุมซ้ายบนของมินิแมพตลอดเวลาที่เล่น (เช่น "Lobby A",
"Catwalk Mid") — เห็นชื่อนี้บนจอเกมแล้วมาเปิดหน้าแผนที่ (Numpad /) ก็จะเห็น**จุดเทาจาง +
ชื่อเดียวกัน**แปะไว้เป็นป้ายอ้างอิง ช่วยให้รู้ทันทีว่าหมุดเลขไหนอยู่ใกล้ตัวที่สุด — เทียบด้วยตาเอง
ไม่ต้องแคป/วิเคราะห์ภาพเลยก็ใช้ได้ หรือจะให้โปรแกรม**อ่านชื่อให้อัตโนมัติ**ก็ได้ (ดูหัวข้อ
["หาหมุดจากชื่อโซนอัตโนมัติ"](#หาหมุดจากชื่อโซนอัตโนมัติ-ocr) ด้านล่าง)

ตั้งค่าครั้งแรก (ทำได้ทีละแมพ ไม่ต้องรีบให้ครบทุกแมพ):

```bash
python tools/fetch_callouts.py
```

ดึง**ชื่อโซน**ของทุกแมพจาก valorant-api.com มาเตรียมไว้ (รันซ้ำได้เรื่อยๆ เอาแค่ชื่อใหม่
ที่ยังไม่เคยมี ของเดิมที่วางตำแหน่งไว้แล้วไม่โดนแตะ)

```bash
python tools/fetch_callout_reference.py     # โหลดรูปอ้างอิงจาก tracker.gg
python tools/auto_place_callouts.py         # วางตำแหน่งให้อัตโนมัติทุกแมพ (ดูหัวข้อล่าง)
```

จากนั้นค่อยเปิดหน้าวางตำแหน่งเพื่อ**ตรวจ/แก้อันที่เพี้ยน + วางอันที่ระบบอ่านไม่ออก**:

```bash
python tools/place_callouts.py
python tools/place_callouts.py --map ascent    # เปิดมาแล้วกรองแมพนี้ไว้ก่อน
```

เลือกชื่อจากลิสต์ซ้าย (✓ = วางแล้ว, พิมพ์ค้นหาได้ถ้ารายชื่อยาว) แล้ว **คลิก 1 ทีบนแผนที่กลาง**
เพื่อวางตำแหน่ง เสร็จแล้วเด้งไปชื่อถัดไปที่ยังไม่ได้วางให้เอง — ชื่อที่ API ให้มาไม่ตรงกับที่จอเกมโชว์เป๊ะทุกตัวก็แก้ใน
ช่องข้อความได้เลย ไม่ต้องแก้ไฟล์เอง

**ขวาสุดมีรูปอ้างอิงจาก tracker.gg** (มีชื่อโซน + สีแบ่งเขตกำกับไว้พร้อมแล้ว) ให้ดูว่าแต่ละชื่อ
อยู่ตรงไหนของแมพ ไม่ต้องนึกจากความจำ ดาวน์โหลดครั้งแรกด้วย `fetch_callout_reference.py`
(เก็บแยกไว้ที่ `assets/callout_reference/` **ไม่ใช่รูปแผนที่จริง** ไม่กระทบพิกัดหมุดใดๆ ทั้งสิ้น
ใช้ดูอ้างอิงเฉยๆ) — รูปอ้างอิงมักหมุนคนละมุมกับแผนที่ของเรา หมุนฝั่งไหนก็ได้ให้ตรงกัน:
**"หมุนรูปอ้างอิง ⟳"** (หรือ `R`) หมุนรูป tracker.gg · **"หมุนแผนที่หลัก ⟳"** (หรือ `Shift+R`)
หมุนแผนที่ของเราเอง — คลิกวางได้ตามปกติแม้หมุนอยู่ พิกัดที่เซฟยังถูกต้องเหมือนเดิมทุกประการ
จะได้ไม่ต้องนึกหมุนในหัวเทียบตำแหน่งจนเวียนหัว

> พิกัดดิบจาก API เชื่อไม่ได้ (ปัญหาเดียวกับป้าย A/B/C ด้านบน — บางแมพหมุนแกนไปจากรูป
> minimap) จึงดึงมาแค่ "ชื่อ" อัตโนมัติ ส่วน "ตำแหน่ง" ต้องคลิกวางเองทีละชื่อเสมอ

#### วางตำแหน่งให้อัตโนมัติ (ไม่ต้องคลิกเองทีละชื่อ)

```bash
python tools/auto_place_callouts.py              # ทุกแมพ
python tools/auto_place_callouts.py --map bind   # แมพเดียว
```

รูปอ้างอิงของ tracker.gg **มีชื่อโซนพิมพ์กำกับไว้ตรงตำแหน่งจริงอยู่แล้ว** ถ้ารู้ว่าต้องหมุน/ย่อ/
เลื่อนรูปนั้นเท่าไหร่ถึงจะทับกับรูปแผนที่ของเรา ก็แปลงตำแหน่งป้ายทุกอันมาเป็นพิกัดของเราได้
ทีเดียวทั้งแมพ เครื่องมือนี้ทำ 3 ขั้นให้เอง:

1. **หามุมหมุนเอง** — เอา "เงาของแมพ" มาเทียบกันตรงๆ ลองหมุน 0/90/180/270° แล้วดูว่ามุมไหน
   ทับกันมากสุด (มุมที่ถูกได้ 0.81-1.00 มุมที่ผิดได้แค่ ~0.3-0.5 แยกออกชัดมาก) — แต่ละแมพหมุน
   คนละมุมกันจริงๆ เช่น bind 0° · icebox 90° · summit 180° · ascent 270°
2. **อ่านป้ายในรูปอ้างอิงด้วย OCR** — Windows OCR คืนกรอบของข้อความมาด้วย จึงรู้ตำแหน่งของแต่ละ
   ป้าย · **อ่านหลายขนาดแล้วรวมผล** เพราะแต่ละขนาดอ่านได้คนละชุด (ผังโซน summit: ขยาย 4 เท่า
   อ่านได้ 18 ป้าย · 5 เท่าได้เพิ่มอีก 2 · 8 เท่าถึงจะอ่าน MID FOUNTAIN ถูก) แล้วเอาค่ากลาง
   ของทุกรอบเป็นตำแหน่งจริง
3. **จับคู่ชื่อ** กับรายชื่อโซนที่รู้จัก — ตัวเดียวกับที่แอปหลักใช้ตอนเล่นจริง จึงไม่สนลำดับคำ
   ด้วย (ผังเขียน `A LOBBY` ส่วนที่เก็บไว้คือ `Lobby A`) และถ้าคล้ายสองชื่อพอๆ กันจะไม่เดา

**ไม่แตะชื่อที่วางตำแหน่งเองไว้แล้ว** (ของที่คลิกเองแม่นกว่าเสมอ) — ถ้าอยากให้ทับด้วยต้องสั่ง
`--overwrite` เอง

> **ความแม่นที่วัดได้จริง**: เทียบกับจุดที่วางเองไว้ก่อนแล้ว ห่างเฉลี่ย **1.5-3%** ของความกว้าง
> แผนที่ — พอสำหรับงานนี้เพราะชื่อโซนกินพื้นที่กว้างกว่านั้นมาก **แต่ควรเปิด `place_callouts.py`
> ดูสักรอบ** จะเห็นจุดที่วางให้ทั้งหมด อันไหนเพี้ยนคลิกแก้ได้ทันที
>
> ชื่อที่ OCR อ่านขาด/อ่านแล้วคล้ายหลายชื่อจนไม่กล้าเดา จะถูกข้ามไว้ให้คลิกวางเอง (ตอนนี้
> เหลือ 10 ชื่อจาก 300 ทั้งหมด)

**รูปอ้างอิงเอามาจากที่อื่นก็ได้** — `assets/callout_reference/<แมพ>.png` เป็นแค่ไฟล์รูป ใครจะ
เอาผังโซนจากเว็บไหนมาวางทับก็ได้ (tracker.gg ยังไม่มีผังของ summit จึงต้องหามาเอง) รองรับทั้ง
รูปพื้นหลังโปร่งใสและ **รูปที่มีฉากหลังทึบ** (เช่นภาพที่แคปมาจากเว็บ) — กรณีหลังจะหาเงาแมพจาก
ความสว่างแทนช่องอัลฟา และตัดกล่องชื่อโซนออกจากเงาให้เอง ไม่งั้นกรอบจะกว้างเกินจริงจนทาบเพี้ยน

### หาหมุดจากชื่อโซนอัตโนมัติ (OCR)

วางชื่อโซนไว้ครบแล้ว (หัวข้อบน) ก็ใช้ปุ่มนี้ให้โปรแกรม**อ่านชื่อเองแล้วชี้ไปหมุดที่ใกล้ที่สุด
ให้เลย** ไม่ต้องเปิดแผนที่ไปไล่หาด้วยตาเอง:

1. กด **Insert** ปุ่มเดียว กลางเกม ไม่ต้องแตะเมาส์ ไม่ต้อง Win+Shift+S
   (ใช้ได้ทุกหน้า ทั้งหน้าแผนที่และหน้ากริด)
2. โปรแกรม**แคปมุมซ้ายบนของจอเกมเอง** (จอที่ไม่ใช่จอที่หน้าต่างโปรแกรมอยู่) — กรอบเริ่มต้น
   กว้าง 35% x 50% ของจอ ครอบมินิแมพกับป้ายชื่อโซนใต้มินิแมพไว้แล้ว ไม่ต้องตั้งอะไรก่อนใช้
3. โปรแกรมอ่านตัวหนังสือจากรูปที่แคป เทียบกับชื่อโซนที่วางตำแหน่งไว้แล้วของแมพปัจจุบัน — **ค้นหา
   หมุดข้ามทั้งบุกและตั้งรับ** (ไม่ยึดว่าตอนนี้เซ็ตฝั่งไหนไว้) แล้ว**เข้าหน้าแผนที่พร้อมไฮไลต์หมุด
   ที่ใกล้ชื่อนั้นที่สุดให้เอง** (สลับฝั่งให้ตรงกับหมุดที่เจอด้วย) — เห็นหมุดข้างเคียงทั้งหมดในย่าน
   เดียวกันทันที กด**เลขเดิมซ้ำ**เพื่อยืนยันเข้าไปดูสูตร หรือกดเลขอื่นถ้าหมุดที่ใช่จริงๆ อยู่ใกล้ๆ
   กัน (ชื่อโซนหนึ่งชื่ออาจมีหลายหมุดซ้อนกันอยู่)

ทุกครั้งที่กด จะขึ้นข้อความบอกว่า**จับคู่ชื่อ/ฝั่งอะไรไป** เสมอ (เช่น `Lobby A → บุก`) แม้ตอน
สำเร็จก็ตาม — เพราะฟีเจอร์นี้พึ่ง OCR + จับคู่ชื่อคล้ายๆ กัน ไม่ได้แม่น 100% เหมือนปุ่มอื่นในแอป
เห็นข้อความนี้แล้วเช็คได้ทันทีว่าตรงกับจุดที่ยืนจริงไหม

**ไม่เดามั่วเด็ดขาด** — อ่านไม่ออก/แคปจอไม่ติด/ไม่มีชื่อไหนตรงพอ/แมพนี้ยังไม่มีหมุดเลย
ล้วนขึ้นข้อความบอกตรงๆ แทนที่จะกระโดดไปมั่วๆ

ในกรอบที่แคปมามีตัวหนังสืออื่นติดมาด้วยเป็นปกติ (เลขเวลา สกอร์ ชื่ออื่นบนมินิแมพ) — โปรแกรม
อ่านแยกเป็น**รายบรรทัด**แล้วเลือกบรรทัดที่คล้ายชื่อโซนที่สุดเอง บรรทัดขยะตกไปเองเพราะคะแนน
ความคล้ายต่ำเกินเกณฑ์ ไม่ต้องแคปให้พอดีป้ายเป๊ะๆ

#### ปรับกรอบที่แคป / แคปจอเกมไม่ติด

ทดสอบว่าแคปจอเกมได้ไหม (**เปิดเกมค้างไว้ก่อน** แล้วมีเวลา 5 วิสลับกลับเข้าเกม):

```bash
LineupMaster.exe --test-capture
```

จะเซฟภาพที่แคปได้เป็น `capture-test.png` ข้างๆ โปรแกรมให้เปิดดูเอง พร้อมพิมพ์ทุกบรรทัดที่ OCR
อ่านได้และบอกว่าจะเลือกชื่อโซนไหน

อยากบีบกรอบให้เหลือเฉพาะป้ายชื่อโซน (อ่านไวขึ้น แม่นขึ้น) เปิด **"เลือกกรอบแคปชื่อโซน"** แล้ว
ลากกรอบเอาเอง — มีปุ่ม "ทดสอบอ่าน" ให้เช็คทันทีว่าอ่านได้ตรงไหม กดบันทึกแล้วใช้ได้เลยไม่ต้อง
รีสตาร์ตแอปหลัก (เก็บลง `capture.json`)

> **ถ้าได้ภาพดำ** แปลว่าเกมตั้งเป็นเต็มจอแบบผูกขาด (Fullscreen) ซึ่งวิธีแคปแบบนี้เข้าไม่ถึง —
> ตั้งในเกมเป็น **Windowed Fullscreen** แล้วลองใหม่ · ระหว่างนี้ยังใช้วิธีเดิมได้ทุกอย่าง:
> แคปเองด้วย **Win+Shift+S** แล้วกด **Insert** โปรแกรมจะรู้เองว่าแคปจอไม่ติดแล้วหยิบรูปจาก
> คลิปบอร์ดมาใช้แทน (ขึ้นข้อความต่อท้ายว่า "จากคลิปบอร์ด" ให้เห็นด้วย)

> ชื่อโซนหนึ่งชื่อมักครอบพื้นที่กว้าง (ไม่ใช่จุดเดียว) จุดอ้างอิงที่ปักไว้ตอน `place_callouts.py`
> จึงเป็น "จุดเริ่มต้นที่ใกล้" ไม่ใช่ "ตรงเป๊ะเสมอ" — ถ้ายืนอยู่ขอบโซนหรือมีหลายหมุดซ้อนกันอยู่ใกล้ๆ
> หมุดที่ไฮไลต์ให้อาจไม่ใช่หมุดที่ตั้งใจเป๊ะ แต่เพราะเข้าหน้าแผนที่ (ไม่ใช่กระโดดเข้ากริดตรงๆ)
> จึงเห็นหมุดข้างเคียงทั้งหมดพร้อมกันอยู่แล้ว เลือกหมุดที่ใช่จริงๆ เองได้ทันทีโดยไม่ต้องกดอะไรเพิ่ม

> **ลำดับคำไม่ตรงกันไม่เป็นไร** — จอเกมโชว์ "Lobby A" แต่ชื่อที่ดึงมาจาก API เก็บเป็น "A Lobby"
> ระบบเทียบทั้งแบบตรงๆ และแบบ**เรียงคำใหม่ก่อนเทียบ** แล้วเอาค่าที่ดีกว่า จึงรู้ว่าเป็นชื่อเดียวกัน
> โดยที่กติกา "คล้ายสองชื่อพอๆ กันจะไม่เดา" ยังทำงานเหมือนเดิม ไม่ต้องไปแก้ชื่อให้ตรงกับจอเกมเอง
>
> (วัดกับข้อมูลจริงทั้ง 13 แมพ ทุกชื่อที่วางตำแหน่งไว้ ลองทั้งสองลำดับคำ รวม 538 กรณี —
> เทียบตรงๆ อย่างเดียวผ่าน 74.9% เพิ่มแบบเรียงคำแล้วผ่าน **100%** · ก่อนแก้จุดนี้ ยืนที่ Lobby A
> แล้วกดปุ่มจริงๆ ได้ "ไม่รู้จักชื่อนี้" เพราะ "A Lobby" กับ "B Lobby" ได้คะแนนเท่ากันเป๊ะ)

> **จับคู่ไม่ได้จะบอกด้วยว่าอ่านได้ว่าอะไร** เช่น `อ่านได้ "Lobby A" แต่ไม่มีชื่อไหนตรงพอ
> (ใกล้สุด: A Lobby)` — เห็นทันทีว่าพังตรงไหน (กรอบที่แคปผิด / OCR อ่านเพี้ยน / ชื่อที่เก็บไว้
> ไม่ตรง) ไม่ต้องเดาเอง

ใช้ **Windows OCR ที่ติดมากับเครื่องอยู่แล้ว** (ตัวเดียวกับที่ Snipping Tool ใช้ตอน "คัดลอก
ข้อความจากรูป") ไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องต่อเน็ต — แต่ **ต้องรันด้วย Python 3.12** (ดู
คำเตือนหัวข้อติดตั้งด้านบน) ไม่งั้นปุ่มนี้จะใช้ไม่ได้ (ส่วนอื่นของโปรแกรมไม่กระทบ)

ทดสอบว่า OCR ใช้งานได้ไหมโดยไม่ต้องเล่นเกม:

```bash
.venv\Scripts\python.exe -m lineupmaster --check-ocr
```

> **ทำไมไม่ใช้ Numpad**: numpad เต็มแล้ว — บนหน้าแผนที่ เลข **1-9 ถูกใช้เลือกหมุดทั้งหมด**
> (รวม 4/5/6) ส่วน `0 + - . / *` ก็มีหน้าที่อยู่แล้ว ไม่เหลือปุ่มไหนว่างพร้อมกันทั้งสองหน้าเลย
> จึงใช้ **Insert** (อยู่ชิดซ้าย numpad มือเดียวกดถึง และ VALORANT ไม่ได้ผูกปุ่มนี้ไว้) —
> เปลี่ยนเป็นปุ่มอื่นได้ที่ `hotkeys: locate:` ใน `config.yaml` (ใช้ชื่อเช่น `delete`, `home`,
> `end`, `page up`, `f9`, `mouse4`)

```yaml
  monitor: 1          # 1 = LG ULTRAWIDE (จอดู), 2 = AOC (จอเล่นเกม)
  fullscreen: false   # false = ไร้ขอบเต็มจอ แต่ลากย้ายจอได้
  max_images: 0       # 0 = โชว์ทุกรูปในกลุ่ม
  show_labels: false  # ถ้าอยากได้รูปล้วนๆ ไม่มีชื่อทับ
  equal_size: true    # ทุกรูปขนาดเท่ากัน / false = รูปแรกใหญ่กว่า
  start_on_map: true  # เปิดโปรแกรมมาที่หน้าแผนที่เลย / false = เปิดมาที่กริดรูปแบบเดิม
```

แมพและฝั่งล่าสุดถูกจำไว้ที่ `last-view.json` เปิดโปรแกรมใหม่ก็อยู่ที่เดิม

ไฟล์เดียวกันยังนับด้วยว่าซูมดูรูปไหนไปกี่ครั้ง (นับตอนกด **Numpad 5** เท่านั้น)
แล้วดันรูปที่ใช้บ่อยขึ้นมาไว้ต้นกลุ่มของจุดนั้น — ยิ่งเล่นยิ่งไม่ต้องกด 4/6 หา
อยากล้างค่าให้กลับไปเรียงตามชื่อไฟล์ ก็ลบ `last-view.json` ทิ้ง

## รัน

ดับเบิลคลิก `run.bat` (อย่าปิดหน้าต่างคอนโซลที่โผล่มา — ปิดคือปิดโปรแกรม)

เปิดได้ทันที ไม่ต้องรอโหลดโมเดลอะไรแล้ว

## บิ้วเป็น exe (เครื่องปลายทางไม่ต้องมี Python)

```bash
.venv\Scripts\python.exe tools\build_exe.py
```

ได้ `dist/LineupMaster/` ขนาดราว **160 MB** (ไม่นับคลังรูป) ก๊อปทั้งโฟลเดอร์ไปวางเครื่องไหน
ก็รันได้เลย ไม่ต้องลง Python ไม่ต้องรัน `setup.bat`

> **ปิด LineupMaster ให้หมดก่อนบิ้ว** (ทั้งโปรแกรมหลักและเครื่องมือทุกตัว) — ตัวบิ้วเช็คให้แล้ว
> ถ้ายังเปิดค้างอยู่จะไม่ยอมเริ่มและไม่แตะ `dist/` เลย เพราะ PyInstaller ลบ `dist/LineupMaster`
> ทิ้งทั้งโฟลเดอร์ก่อนสร้างใหม่ ถ้ามีโปรแกรมเปิดค้างมันจะล็อก `qwindows.dll` ไว้ ทำให้ลบได้แค่
> บางส่วนแล้วล้มกลางทาง — **ของที่ลบไปก่อนถึงไฟล์ที่ล็อกหายจริง** (เคยทำ `assets/maps` หายเกลี้ยง
> จนแผนที่ในทุกเครื่องมือหายไปหมดมาแล้ว) ถ้าเกิดล้มกลางทางจริง ตัวบิ้วจะเอา config/assets กลับ
> เข้า `dist/` ให้เองก่อนจบ ของเดิมจึงยังใช้ต่อได้

| ไฟล์ในโฟลเดอร์ | ทำอะไร |
|---|---|
| `LineupMaster.exe` | โปรแกรมหลัก (จอที่สอง + numpad) |
| `จัดการคลังไลน์อัพ.lnk` | = `LineupMaster.exe manage` |
| `จิ้มหมุดบนแผนที่.lnk` | = `LineupMaster.exe pin` |
| `โหลดรูปแผนที่.lnk` | = `LineupMaster.exe maps` |
| `ดึงชื่อโซน.lnk` | = `LineupMaster.exe callouts` |
| `โหลดรูปอ้างอิงชื่อโซน.lnk` | = `LineupMaster.exe callout-reference` |
| `วางตำแหน่งชื่อโซน.lnk` | = `LineupMaster.exe place-callouts` |
| `วางตำแหน่งชื่อโซนอัตโนมัติ.lnk` | = `LineupMaster.exe auto-callouts` |
| `เลือกกรอบแคปชื่อโซน.lnk` | = `LineupMaster.exe capture-region` |

**เป็น exe ตัวเดียวที่แยกงานด้วยคำสั่งย่อย** ไม่ได้บิ้วแยกหลายตัว เพราะ PySide6 ใหญ่มาก
ถ้าบิ้วแยก Qt จะถูกก๊อปซ้ำทุกตัว — shortcut ข้างบนคือตัวเดียวกันแต่ส่ง argument ต่างกัน
(คำสั่งย่อยพวกนี้ใช้ตอนรันจากซอร์สได้ด้วย เช่น `python -m lineupmaster manage`)

### ต้องย้ายข้อมูลเข้าไปเอง

ตัวบิ้ว**ไม่ก๊อป `lineups/` ให้** เพราะคลังรูปหนักหลายร้อยเมกะไบต์ ถ้าก๊อปจะกลายเป็นสองชุด
แล้วเผลอแก้คนละที่จนข้อมูลเพี้ยน — ให้**ย้าย** `lineups/`, `positions.json`,
`last-view.json` เข้าไปวางในโฟลเดอร์นั้นเอง (หรือใช้ `--with-data` ถ้าจะเอาไปทั้งชุดใส่ USB)

ข้อมูลทั้งหมดอยู่**ข้างนอก** exe เสมอ ไม่ได้ฝังเข้าไปข้างใน จะได้แก้รูป/แก้ config ได้
โดยไม่ต้องบิ้วใหม่ (ดู `src/lineupmaster/paths.py`)

### เรื่อง antivirus

โปรแกรมนี้ดักปุ่มคีย์บอร์ดระดับ OS (numpad) พอถูกแพ็กด้วย PyInstaller จะเข้าลักษณะเดียวกับ
keylogger ทำให้ AV บางตัวเตือนได้ — **ทดสอบกับ Windows Defender แล้วผ่าน ไม่เจออะไร**
แต่ถ้าเครื่องอื่นเตือน ต้องใส่ข้อยกเว้นให้โฟลเดอร์เอง (ตัวบิ้วปิด UPX ไว้แล้วเพราะยิ่งบีบยิ่งโดนจับ)

ถ้าไม่อยากยุ่งกับเรื่องนี้เลย ใช้ `setup.bat` แทนได้ — รันผ่าน `python.exe` ที่ Windows
รู้จักอยู่แล้ว แทบไม่เจอปัญหา AV

## ย้ายไปเครื่องอื่น

ก๊อปทั้งโฟลเดอร์ไปได้เลย **ยกเว้น `.venv/`** แล้วที่เครื่องใหม่ดับเบิลคลิก:

```
setup.bat
```

ครั้งเดียวจบ — มันจะหา Python ในเครื่อง สร้าง `.venv` ใหม่ แล้วลงแพ็กเกจให้

### ทำไมต้องทำแบบนี้

`.venv/` **ย้ายข้ามเครื่องไม่ได้** เพราะข้างในฝัง path เต็มของ Python เครื่องเดิมไว้
(เปิด `.venv/pyvenv.cfg` ดูได้) พอเอาไปเปิดในเครื่องที่ชื่อผู้ใช้ไม่เหมือนกัน มันจะฟ้องว่า:

```
did not find executable at 'C:\Users\PC\AppData\Local\Python\...\python.exe'
```

อ่านเผินๆ เหมือนโปรแกรมเช็คชื่อเครื่อง แต่จริงๆ คือ **path เก่าที่ค้างอยู่ในไฟล์ตั้งค่าของ
`.venv`** เฉยๆ ไม่มีการเช็คชื่อเครื่องที่ไหนในโค้ดเลย

`run.bat` ตรวจให้แล้วว่า `.venv` ใช้ได้จริงไหมก่อนเปิด ถ้าไม่ได้จะบอกให้ไปรัน `setup.bat`
ส่วน `setup.bat` ถ้าเจอ `.venv` ที่ก๊อปมา จะบอกว่ามันชี้ไป path ไหนแล้วถามก่อนลบสร้างใหม่
(`.venv` เป็นแค่ที่เก็บแพ็กเกจ **ไม่มีรูปไลน์อัพหรือหมุดอยู่ข้างใน**)

### ข้อมูลของคุณอยู่ไฟล์ไหนบ้าง

ก๊อปพวกนี้ไปด้วยถึงจะได้ของครบ — **ถ้าใช้ `dist/LineupMaster/` เป็นตัวหลัก (แนะนำ) ไฟล์ 4
อันแรกอยู่ในนั้นเลย ไม่ต้องหาที่ root**:

| ไฟล์/โฟลเดอร์ | เก็บอะไร |
|---|---|
| `lineups/` | รูปไลน์อัพทั้งหมด + gif + โน้ต |
| `positions.json` | หมุดบนแผนที่ |
| `callouts.json` | ป้ายชื่อโซนที่วางตำแหน่งไว้ (ดูหัวข้อ [ป้ายชื่อโซน](#ป้ายชื่อโซน-เทียบกับที่เกมบอกบนจอ)) |
| `meta.json` | สกิล / ⭐ ไม้ตาย / แท็กสถานการณ์ / จำนวนครั้งที่ซ้อม ของแต่ละรูป |
| `capture.json` | กรอบบนจอเกมที่ปุ่ม **Insert** จะแคปมาอ่าน (ไม่มีไฟล์นี้ = ใช้ค่าเริ่มต้น มุมซ้ายบน) |
| `last-view.json` | แมพ/ฝั่งล่าสุด + สถิติรูปที่ใช้บ่อย (อยู่ใน `dist/LineupMaster/` เหมือนกัน แต่ไม่ได้มากับ git) |
| `config.yaml`, `aliases.yaml` | การตั้งค่าและคำพ้อง (อยู่ที่ root ของโปรเจกต์) |
| `assets/maps/` | รูปแผนที่ (อยู่ที่ root — ไม่ก๊อปก็ได้ รัน `fetch_maps.py` โหลดใหม่) |
| `assets/callout_reference/` | รูปอ้างอิง tracker.gg (อยู่ที่ root — ไม่ก๊อปก็ได้ รัน `fetch_callout_reference.py` โหลดใหม่) |

> **หมายเหตุสำหรับคนแก้โค้ด**: ไฟล์ `.bat` ต้องเป็น ASCII ล้วน ห้ามใส่ภาษาไทยในบรรทัดที่
> ต้องรัน (เช่น `echo`) เพราะ cmd.exe อ่านไฟล์ `.bat` ด้วย codepage ของระบบ ไม่ใช่ UTF-8
> ตัวอักษรไทยจะทำให้ตัวแปลคำสั่งเพี้ยนจนรันคำสั่งผิดตัวได้ — ข้อความไทยทั้งหมดอยู่ใน
> `tools/setup.py` แทน
