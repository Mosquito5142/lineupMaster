# LineupMaster

ผู้ช่วยเปิดรูปไลน์อัพ VALORANT บนจอที่สอง **ควบคุมด้วยแป้น Numpad** —
กดปุ่มเดียวได้รูปที่ต้องการ ไม่ต้องละมือจากเกม ไม่ต้องออกจากหน้าเกม

- **กดปุ่ม = ได้สิ่งนั้น 100% ทุกครั้ง** ไม่มีการฟังเสียง ไม่มีการเดา
- **1 ไลน์อัพ = 1 รูป** เอารูปที่ดูแล้วเข้าใจครบในภาพเดียวมาวางไว้
- **จอ 2 มีแค่รูป** กับแถบบอกสถานะบางๆ ด้านบน

## เริ่มจากศูนย์ (โคลน/ดึงโค้ดมาใหม่)

**ข้อมูลผู้ใช้ทั้งหมด (`lineups/` + หมุด + ชื่อโซน + แท็ก) ไม่ได้อยู่ใน git เลยสักไฟล์** —
เก็บรวมกันไว้ที่ **Google Drive** แทน (ดูเหตุผลใน `.gitignore`) จะ**อัปโหลด/ดาวน์โหลดเอง
เป็นครั้งคราว** (ลากทั้งโฟลเดอร์ `dist/LineupMaster/` ขึ้น Drive ตอนอยากสำรอง แล้วดาวน์โหลด
กลับมาตอนต้องใช้ที่เครื่องอื่น) หรือจะให้ **Google Drive Desktop ซิงก์ต่อเนื่องอัตโนมัติ** ก็ได้
แล้วแต่สะดวก — ไม่ต้อง commit/pull ผ่าน git เอง ไม่ว่าจะเลือกวิธีไหน โคลนโค้ดมาอย่างเดียวจะยัง
ไม่มีข้อมูลผู้ใช้เลย ต้องทำ 4 ขั้นนี้ก่อน:

1. **ติดตั้ง**

   ```bash
   setup.bat
   ```

   ดับเบิลคลิกก็ได้ — หา Python ในเครื่อง สร้าง `.venv` แล้วลงแพ็กเกจให้ (รายละเอียดอยู่หัวข้อ
   [ย้ายไปเครื่องอื่น](#ย้ายไปเครื่องอื่น) ด้านล่าง)

   > **ต้องมี Python 3.12 ในเครื่อง** (3.8-3.12 ก็ได้ แต่แนะนำ 3.12) — ฟีเจอร์ "อ่านชื่อโซน
   > ด้วย OCR" (ดูหัวข้อ [ป้ายชื่อโซน](#ป้ายชื่อโซน-เทียบกับที่เกมบอกบนจอ)) ใช้แพ็กเกจ
   > `winsdk` ซึ่งยังไม่มีไฟล์สำเร็จรูปให้ Python 3.13/3.14 — `setup.bat` จะลองหา `py -3.12`
   > ก่อนเสมอ ถ้าไม่มีจะใช้ Python เวอร์ชันอื่นแทนแต่เตือนไว้ (ส่วนอื่นของโปรแกรมยังใช้ได้ปกติ
   > แค่ปุ่มอ่านชื่อโซนจะใช้ไม่ได้)

2. **บิ้วโปรแกรม**

   ```bash
   .venv\Scripts\python.exe tools\build_exe.py
   ```

   ได้ `dist\LineupMaster\LineupMaster.exe` พร้อม shortcut ของเครื่องมือย่อยทั้งหมด — **ใช้
   `dist\LineupMaster\` เป็นตัวหลักจากนี้ไป** (ดูหัวข้อ [บิ้วเป็น exe](#บิ้วเป็น-exe-เครื่องปลายทางไม่ต้องมี-python))
   — ตอนนี้ยังไม่มีข้อมูลผู้ใช้อะไรอยู่ข้างในเลย (คลังว่างเปล่า) เป็นเรื่องปกติ ไปทำขั้นถัดไป

3. **ดึงข้อมูลผู้ใช้ทั้งชุดจาก Google Drive**

   โหลดจาก Google Drive มาวางไว้ **ข้างๆ `LineupMaster.exe`** ให้ได้โครงสร้างแบบนี้:

   ```
   dist/LineupMaster/
   ├── LineupMaster.exe
   ├── lineups/          <- โฟลเดอร์รูปไลน์อัพ
   ├── positions.json    <- หมุดบนแผนที่
   ├── callouts.json     <- ป้ายชื่อโซน
   ├── meta.json         <- สกิล/ไม้ตาย/แท็ก
   ├── capture.json      <- กรอบแคปชื่อโซน (ถ้าเคยตั้งไว้)
   └── ...
   ```

   จะลากทั้งโฟลเดอร์ `dist/LineupMaster/` (ไม่ใช่แค่ `lineups/`) ขึ้น Google Drive เอง
   ผ่านหน้าเว็บ/แอปมือถือเป็นครั้งคราวก็ได้ — จะได้ไฟล์ข้างบนครบทีเดียวทั้งหมด ง่ายดี ไม่ต้อง
   ตั้งค่าอะไรเพิ่ม (แนะนำถ้าไม่อยากยุ่งกับโปรแกรมซิงก์ต่อเนื่อง)

   **เครื่องที่เคยใช้อยู่แล้ว อย่าแตกทับของเดิม** เพราะของที่เครื่องนั้นเพิ่มเองจะหาย ให้ไปใช้ [รวมคลังจากโฟลเดอร์อื่น](#อัปเดตโปรแกรม--ย้ายของระหว่างสองเครื่อง-รวมคลัง) แทน

   > อยากให้อัปเดตอัตโนมัติตลอดโดยไม่ต้องอัปโหลดเองก็ได้ — ติดตั้ง **Google Drive for
   > Desktop** แล้วเลือกเฉพาะโฟลเดอร์ `dist/LineupMaster/` ให้ซิงก์ (**อย่าเลือกทั้งโฟลเดอร์
   > โปรเจกต์** `lineupMaster/` เพราะจะไปซิงก์ `.venv/`, `.git/`, ไฟล์ตัว build ที่หนักและไม่
   > จำเป็นไปด้วย เปลืองโควต้าและซิงก์ช้าโดยใช่เหตุ)

   ตรวจว่าวางถูกที่ไหม:

   ```bash
   dist\LineupMaster\LineupMaster.exe --list
   ```

   ควรเห็น `รวม N รูป` ท้ายผลลัพธ์ (ไม่ใช่ `ไม่เจอไลน์อัพเลยใน ...`)

4. **เปิดโปรแกรม**

   เปิด `dist\LineupMaster\LineupMaster.exe` → หน้าเข้าโปรแกรม → กด "เข้าโปรแกรม"

รูปแผนที่ (`assets/maps/`) กับรูปอ้างอิงชื่อโซน (`assets/callout_reference/`) มากับ **git**
(เป็นข้อมูลอ้างอิงคงที่ ไม่ใช่ของที่ผู้ใช้แก้ จึงต่างจาก 4 ไฟล์ข้างบน) — อยู่ที่ root ของ
โปรเจกต์ ขั้นตอนบิ้วจะก๊อปเข้า `dist\LineupMaster\assets\` ให้เองอัตโนมัติ ไม่ต้องรัน
`fetch_maps.py` / `fetch_callout_reference.py` เอง เว้นแต่อยากได้เวอร์ชันใหม่กว่า (ดูหัวข้อ
[หน้าแผนที่](#หน้าแผนที่-ชั้น-0))

ส่วน `last-view.json` (แมพ/ฝั่งล่าสุด + สถิติใช้บ่อย) ไม่ได้มากับ Drive/git ไหนเลย — เป็นแค่
สถิติส่วนตัวที่เปิดโปรแกรมครั้งแรกจะสร้างไฟล์ใหม่เองอัตโนมัติ ไม่ต้องทำอะไร (ถ้าอยากให้สถิติ
"ใช้บ่อย" ตามไปด้วยตอนย้ายเครื่อง ก็เอาไฟล์นี้ขึ้น Drive ไปด้วยได้เหมือนกัน)

> **อยากรันจากซอร์สตรงๆ ด้วย `run.bat` แทนการบิ้ว exe?** ทำได้ แต่ `run.bat` อ่านข้อมูลจาก
> root ของโปรเจกต์ ไม่ใช่จาก `dist/LineupMaster/` — ต้องก๊อป
> `dist\LineupMaster\{positions,callouts,meta,capture}.json` มาวางที่ root เองก่อน ไม่งั้น
> จะเห็นคลังว่างเปล่า (ไม่มีหมุด/ชื่อโซน/แท็กเลย)

## ทำไมถึงไม่ใช่โปร

โปรแกรมนี้ **ไม่แตะเกมเลยแม้แต่นิดเดียว**:

- ไม่อ่าน/เขียน memory ของเกม, ไม่ inject DLL, ไม่ hook process เกม
- **ไม่ส่ง input เข้าเกม** — ไม่มี macro, ไม่มี auto-aim, ไม่ขยับเมาส์ให้
- ไม่มี overlay ทับหน้าต่างเกม (เป็นหน้าต่างแยกบนอีกจอ)
- ไม่แคปหน้าจอเกมไปวิเคราะห์, ไม่อ่านไฟล์/log ของเกม
- ดักปุ่มด้วย hook ระดับ OS แบบ **อ่านอย่างเดียว ไม่ suppress** — กลไกเดียวกับ
  Discord push-to-talk, OBS, Steam overlay ที่ใช้กันปกติ

## ปุ่มควบคุม

> **ต้องเปิด NumLock ไว้** ไม่งั้น Windows จะส่ง Numpad เป็นปุ่มลูกศร/End/PgDn แทน
> VALORANT ไม่ได้ผูก Numpad ไว้เลย จึงไม่ชนกับปุ่มในเกม
> (โปรแกรมแยก Numpad ออกจากแป้นเลขแถวบนด้วย virtual key code — กดเปลี่ยนอาวุธ 1-4
> จึงไม่ไปสั่งโปรแกรม)

| ปุ่ม                  | ทำอะไร                                                                                        | ต้องกดบ่อยแค่ไหน                             |
| --------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------- |
| **Numpad +** / **−**  | เปลี่ยนแมพ (วนเฉพาะแมพที่มีรูป)                                                               | ครั้งเดียวต่อเกม — และจำไว้ข้ามการปิดโปรแกรม |
| **Numpad 0**          | สลับ บุก ↔ ตั้งรับ                                                                            | ครั้งเดียวต่อครึ่ง                           |
| **Numpad 1 / 2 / 3**  | ดูเฉพาะจุด A / B / C (กดซ้ำ = กลับไปดูทั้งครึ่ง)                                              | ตามใจ                                        |
| **Numpad .**          | กลับไปดูทั้งครึ่ง                                                                             |                                              |
| **Numpad 4 / 6**      | เลื่อนกรอบเลือกรูป                                                                            |                                              |
| **Numpad 5**          | ซูมรูปที่เลือกเต็มจอ (กดซ้ำ = ออก)                                                            |                                              |
| **Numpad \***         | เล่น/หยุด gif ของรูปที่ซูมอยู่ (ต้องกดซูมก่อน)                                                |                                              |
| **Numpad /**          | เข้า/ออกหน้าแผนที่ — เลือกจาก "จุดที่เรายืน"                                                  | ตอนไม่รู้ว่ามีสูตรอะไรตรงนี้บ้าง             |
| **Numpad 1-9**        | _(เฉพาะบนแผนที่)_ เลือกหมุดเลขนั้น · กดเลขเดิมซ้ำ = เข้าไปดูรูป                               |                                              |
| **Insert**            | แคปชื่อโซนจากจอเกมเอง แล้วชี้หมุดที่ใกล้ที่สุด ([รายละเอียด](#หาหมุดจากชื่อโซนอัตโนมัติ-ocr)) | ตอนไม่แน่ใจว่ายืนตรงไหนบนแผนที่              |
| **F9**                | เปิด/ปิด **โหมดตามตัว** — วงพื้นที่ที่เรายืนอยู่ให้เองเรื่อยๆ ([รายละเอียด](#โหมดตามตัว-f9))  | กดครั้งเดียวตอนเริ่มเกม แล้วปล่อยยาวทั้งเกม  |
| **Delete**            | สลับตัวละคร (ทั้งหมด → โซวา → ไซเฟอร์ → …) ([รายละเอียด](#ตัวกรอง-เล่นหลายตัวละครหลายสกิล))   | ครั้งเดียวตอนเปลี่ยนตัวที่เล่น               |
| **Home**              | สลับสกิล (ทั้งหมด → รีคอน → ช็อก → …)                                                         | ตามสถานการณ์                                 |
| **End**               | เปิด/ปิด "เฉพาะไม้ตาย" ⭐                                                                     | ตอนอยากดูแค่ท่าที่ใช้จริง                    |
| **Page Up**           | สลับแท็กสถานการณ์ (แก้ทางตัวไหน / post-plant)                                                 | ตอนรู้ว่าศัตรูมีตัวไหน                       |
| **Page Down**         | โหมดซ้อม: สุ่มไลน์อัพจากที่กรองอยู่ แล้วซูมให้เลย                                             | ตอนซ้อมในห้องคัสตอม                          |
| **F7**                | ✓ **ใช้ได้จริง** ให้ใบที่เอามาจากคอมมูนิตี้ (กดซ้ำ = ถอน) — คะแนนส่งตอนเปิดแท็บคอมมูนิตี้ในเว็บ ([ตั้งค่าคอมมูนิตี้](docs/community-setup.md)) | หลังใช้ไลน์อัพของเพื่อนแล้วได้ผล |
| **F8**                | ⚑ **แจ้งผิด** ใบที่เลือก/ซูมอยู่ (กดซ้ำ = เอาธงออก) — ใบนั้นยังโชว์แต่มีแถบแดง แล้วไปแก้ทีหลังในเว็บ: แท็บคลัง → ชิป **⚑ ต้องแก้** → จิ้มหมุดใหม่ / **✎ วาด** ลูกศร-วง-ข้อความทับรูป / ลบ แล้วติ๊ก ⚑ ออก | ตอนเจอใบที่หมุดเพี้ยนหรือใช้ไม่ได้ระหว่างเล่น |
| **ลากตรงไหนก็ได้**    | ย้ายหน้าต่างไปอีกจอ                                                                           |                                              |
| **F11** / ดับเบิลคลิก | สลับเต็มจอจริง                                                                                |                                              |
| **Esc**               | ปิดโปรแกรม                                                                                    |                                              |

เปลี่ยนปุ่มได้ใน `config.yaml` → `hotkeys`

## ตัวกรอง (เล่นหลายตัวละคร/หลายสกิล)

พอคลังโตขึ้นและเริ่มเล่นหลายตัว การเห็นทุกอย่างพร้อมกันกลับช้ากว่า — **บล็อก 6 ปุ่มเหนือลูกศร**
(ติดกับ numpad มือเดียวกดถึง) จึงเป็นชุดตัวกรอง:

| ปุ่ม        | กรองอะไร                                      |
| ----------- | --------------------------------------------- |
| **Delete**  | ตัวละคร — เล่นไซเฟอร์อยู่ก็ไม่ต้องเห็นของโซวา |
| **Home**    | สกิล — รีคอนกับช็อกใช้คนละสถานการณ์สิ้นเชิง   |
| **End**     | ⭐ ไม้ตาย — เฉพาะท่าที่ติดดาวไว้ว่าใช้จริง    |
| **Page Up** | สถานการณ์ — `anti-cypher`, `post-plant` ฯลฯ   |

- **กรองแล้วมีผลทุกที่พร้อมกัน** — ทั้งกริดรูป, **หมุดบนหน้าแผนที่**, ปุ่มจุด A/B/C และปุ่ม
  **Insert** (OCR) ใช้ตัวตัดสินตัวเดียวกัน จึงไม่มีทางที่กริดกับแผนที่จะไม่ตรงกัน
- **หัวจอบอกเสมอว่ากรองอะไรอยู่** (`กรอง: ไซเฟอร์ · กับดัก · ⭐`) — กันเปิดกรองค้างแล้วนึกว่ารูปหาย
- **วนเฉพาะค่าที่มีจริง** ของแมพ/ฝั่งนั้น ไม่ต้องกดผ่านตัวเลือกว่างๆ
- ตัวละคร/สกิล **จำข้ามการปิดโปรแกรม** (เล่นตัวเดิมข้ามวัน) ส่วน ⭐ กับแท็กสถานการณ์
  **ไม่จำ** เพราะเป็นตัวกรองเฉพาะกิจ เปิดค้างข้ามวันแล้วจะงง

### โหมดซ้อม (Page Down)

กดแล้วสุ่มไลน์อัพจากชุดที่กรองอยู่มาซูมให้เลย — เปิดคู่กับห้องคัสตอมแล้วไล่ยิงตามได้เรื่อยๆ
**สุ่มจากใบที่ซ้อมน้อยที่สุดก่อน** ไม่ใช่สุ่มล้วน (สุ่มล้วนจะวนเจอใบเดิมซ้ำๆ แล้วบางใบไม่เคยถูก
หยิบเลย) หัวจอบอกด้วยว่า `เคยซ้อมแล้ว 12/40 ใบ`

> นับแยกจากสถิติ "เปิดดูบ่อย" ที่ใช้จัดเรียงรูปในกริด — คนละความหมายกัน ถ้านับรวมกัน
> ลำดับรูปในกริดจะเพี้ยนเพราะการสุ่มซ้อม

### ติดแท็กยังไง

ทำในหน้า **จัดการคลังไลน์อัพ** แถว **"สกิล/แท็ก"**: เลือกสกิล · ติ๊ก ⭐ ไม้ตาย · พิมพ์แท็ก
คั่นด้วย `,` แล้วกด **บันทึกการแก้ไข**

- มีปุ่ม **"ตั้งสกิลนี้ให้ทุกใบที่กรองอยู่"** — กรองเป็นแมพ/ฝั่ง/จุดทางซ้ายก่อน แล้วเหมาทีเดียว
  (ไว้ติดสกิลย้อนหลังให้ของเก่าทั้งคลัง ไม่ต้องกดทีละใบเป็นร้อยครั้ง)
- แท็กเก็บใน **`meta.json`** คีย์ด้วยที่อยู่ของรูป — **ไม่ได้เก็บในชื่อไฟล์** เพราะดาวกับจำนวน
  ครั้งที่ซ้อมเปลี่ยนตลอดเวลา · เปลี่ยนชื่อ/ย้ายรูปแล้วแท็กตามไปเอง
- สกิลที่อ่านได้จากชื่อไฟล์อยู่แล้ว (เช่นตั้งชื่อว่า `recon_...`) ยังใช้ได้เหมือนเดิม —
  `meta.json` เป็นแค่ตัวเติมช่องที่ชื่อไฟล์ไม่ได้บอกไว้

## ดู 4 ชั้น กดเท่าที่อยากละเอียด

```
ชั้น 0  แผนที่               ← กด /        "ยืนตรงนี้ ยิงไปไหนได้บ้าง"
ชั้น 1  ทั้งครึ่ง (ทุกจุด)   ← ค่าเริ่มต้น  ระหว่างตาไม่ต้องกดอะไรเลย
ชั้น 2  เฉพาะจุดที่เลือก      ← กด 1/2/3    รูปใหญ่ขึ้น
ชั้น 3  รูปเดียวเต็มจอ        ← กด 5        ดูพิกัดชัดๆ  ／ กด * ดู gif วิถีลูก
```

ชั้น 0 ถามคนละคำถามกับอีก 3 ชั้น: อีก 3 ชั้นเรียงตาม **จุดเป้าหมาย** (มาจากโฟลเดอร์)
ส่วนชั้นแผนที่เรียงตาม **จุดที่เรายืน** — ดูวิธีทำที่หัวข้อ "หน้าแผนที่" ข้างล่าง

แถบบนหัวจอบอกตลอดว่าอยู่ไหน:

```
HAVEN   │   ตั้งรับ   │   A [B] C   │   3 รูป
```

`[B]` = กำลังดูจุด B · `·` แทนตัวอักษร = จุดนั้นยังไม่มีรูป

## จัดการคลังแบบเว็บ (ตัวหลักที่แนะนำให้ใช้)

```bash
python tools/web_manage.py
```

เปิดหน้าจัดการในเบราว์เซอร์แทนหน้าต่าง Qt — ทำงานกับ **ไฟล์ข้อมูลชุดเดียวกันเป๊ะ**
(ทุกการแก้ไขวิ่งผ่าน `lineupmaster.library` ตัวเดียวกับของเดิม ของพ่วง gif/โน้ต/หมุด/แท็ก
จึงถูกลากตามไปครบเหมือนกันทุกอย่าง) จะใช้สลับกับหน้า Qt เดิมไปมาก็ได้ ไม่มีปัญหา

> **ไม่เกี่ยวกับโปรแกรมหลักเลย** — ตัวที่รันบนจอที่สองคุม numpad ยังเป็น Qt เหมือนเดิมทุก
> ประการ ไม่ได้ถูกแตะต้อง หน้าเว็บนี้แทนที่แค่ "หน้าจัดการ" ซึ่งนั่งทำหน้าคอมปกติ

หน้านี้มี **2 แท็บ**: `คลังของเรา` (จัดการของที่มีอยู่) และ `หาไลน์อัพจากเว็บ`
(ดึงของใหม่จาก ValoLineups Pro + ValCompanion มาคัด จัดหน้า เขียนทับ ปักหมุด แล้วเก็บ
เข้าคลัง — จบในที่เดียว)

### แท็บ `คลังของเรา`

| ทำอะไร                      | ยังไง                                                                                                                                                                               |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **หาไลน์อัพ**               | ช่องค้นหา + ตัวกรอง แมพ/ฝั่ง/จุด/ตัวละคร/สกิล/แท็ก/⭐/ยังไม่จิ้มหมุด                                                                                                                |
| **แก้ข้อมูล**               | คลิกรูป → แก้ในฟอร์มขวา → **บันทึกการแก้ไข** (เปลี่ยนชื่อ+ย้าย+แท็ก ได้ในคลิกเดียว)                                                                                                 |
| **จิ้มหมุด**                | คลิกบนแผนที่ 2 ครั้ง: จุดยืน → จุดที่ลูกไปตก · `🗑` ลบหมุดใบนี้                                                                                                                     |
| **ซูม/เลื่อน/หมุนแผนที่**   | **หมุนลูกกลิ้งเมาส์** = ซูมตรงจุดที่ชี้ · **ลาก** = เลื่อน · **ดับเบิลคลิก** = พอดีจอ · แถบเลื่อน `↺ ↻` หมุนได้ 0-359°                                                              |
| **ส่องมินิแมพในรูปไลน์อัพ** | รูปไลน์อัพก็ซูม/เลื่อนได้เหมือนแผนที่ — **ลูกกลิ้ง** ซูม · **ลาก** เลื่อน · **ดับเบิลคลิก** พอดีกรอบ (ในสกรีนช็อตมีมินิแมพเล็กๆ ของเกมบอกว่าคนยิงยืนตรงไหน ขยายดูแล้วจิ้มตามได้เลย) |
| **ปรับขนาดช่องดู**          | **ลากเส้นคั่น** ได้ 3 จุด: ระหว่างรายการรูปกับช่องขวา · ระหว่างรูปไลน์อัพกับแผนที่ · ระหว่างรูป+แผนที่กับฟอร์มข้างล่าง (**ดับเบิลคลิกเส้นคั่น** = กลับค่าเริ่มต้น)                  |
| **จอใหญ่**                  | ปุ่ม **⛶ จอใหญ่** ซ่อนรายการรูปทางซ้ายทิ้ง เหลือรูปกับแผนที่เต็มหน้าต่าง · `Esc` ออก                                                                                                |
| **เปลี่ยนใบ**               | ปุ่ม `‹` `›` หรือ **Alt+← / Alt+→** — เลื่อนไปใบก่อนหน้า/ถัดไปในรายการที่กรองอยู่ (ใช้ตอนเปิดจอใหญ่ที่รายการถูกซ่อน)                                                                |
| **ตั้งป้าย A/B/C**          | กดปุ่ม **ป้าย A/B/C** แล้วคลิกตำแหน่งบนแผนที่ (Esc ยกเลิก)                                                                                                                          |
| **เพิ่มรูป**                | ลากไฟล์มาวางในหน้า · **Ctrl+V** วางจากคลิปบอร์ด · ปุ่ม **เพิ่มรูปเข้าคลัง**                                                                                                         |
| **ลบ**                      | ปุ่ม **ลบ** — ย้ายเข้า `.trash/` เหมือนเดิม ไม่ได้ลบถาวร                                                                                                                            |
| **สั่งเหมาหลายใบ**          | **Ctrl+คลิก** เลือกหลายใบ → แถบล่างตั้งสกิล/⭐ ทีเดียวทั้งชุด                                                                                                                       |

### แท็บ `หาไลน์อัพจากเว็บ`

ดึงรายการ **11,000+ ใบจาก 2 เว็บ** (ValoLineups Pro 6,027 · ValCompanion 5,598) มาคัด —
มี **2 โหมด**: **⊞ ตาราง** (คัดทีละหลายใบรวดเดียว) กับ **▭ ทีละใบ** (แต่งรูปได้เต็มที่)
**รูปที่เห็นคือรูปที่จะได้จริง** ชอบก็จัดหน้า/เขียนทับก่อนเก็บได้เลย ไม่ต้องเปิด "ต่อรูปขั้นตอน" ซ้ำ

> ของเยอะขนาดนี้ไล่ดูทีละใบไม่ไหวแน่ — **โหมดตารางคือทางหลัก** ส่วนโหมดทีละใบเอาไว้ใช้
> ตอนเจอใบที่อยากแต่งจริงจัง (คลิกที่ช่องในตารางก็เด้งไปโหมดทีละใบให้เลย)

| ทำอะไร                    | ยังไง                                                                                                                                                             |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **เลือกชุดที่จะดู**       | ตัวกรอง ตัวละคร/แมพ/ฝั่ง/จุด/สกิล/**ต้นทาง**/**ปลายทาง**/**จำนวนขั้น**/**ความยาก**/**เว็บ** + **ช่องค้นหา** (เริ่มที่ sova ให้)                                   |
| **ซ่อนที่มีแล้ว**         | ติ๊ก **ซ่อนที่มีแล้ว** — เทียบเส้นทาง (แมพ+ตัวละคร+ต้นทาง→ปลายทาง) กับคลังเรา แล้วซ่อนใบซ้ำทิ้ง                                                                   |
| **กรองด้วยการจิ้มแผนที่** | กล่อง **กรองด้วยการจิ้มบนแผนที่** — ทุกโซนมี**ตัวเลขบอกว่ามีไลน์อัพกี่ใบ** คลิกครั้งแรก = ต้นทาง · ครั้งที่ 2 = ปลายทาง (ซูม/เลื่อน/หมุนได้)                      |
| **คัดทีละหลายใบ**         | โหมดตาราง: ติ๊กช่องมุมซ้ายบนของแต่ละใบ (หรือ **เลือกทั้งหน้า**) → **✓ เก็บที่เลือกเข้าคลัง** / **✗ ไม่เอาที่เลือก**                                               |
| **จัดหน้าอัตโนมัติ**      | คอลัมน์ (อัตโนมัติ/1-4) · ช่องไฟ · เลขกำกับขั้น · ความกว้างรูปที่ออก                                                                                              |
| **จัดหน้าเอง**            | เครื่องมือ **👆 ย้าย/ย่อขยาย** — คลิกรูปแล้ว**ลากกลางรูปเพื่อย้าย · ลากมุมเพื่อย่อขยาย** จะให้รูปไหนใหญ่กว่ารูปไหนก็ได้ · ปุ่ม **จัดเรียงใหม่** กลับเป็นตารางปกติ |
| **ลบรูปที่ไม่ต้องการ**    | เลือกรูปแล้วกด **🗑 ลบรูปที่เลือก** (หรือปุ่ม **Delete**) — บางท่ามีขั้นที่ไม่จำเป็น ตัดทิ้งได้ · กด **คืนรูปที่ลบ** เอากลับมาได้ ไม่ได้หายถาวร                   |
| **เขียนทับ**              | **✎ ปากกา** วาดมือเปล่า · **╱ เส้นตรง** (ไม่มีหัวลูกศร) · **↗ ลูกศร** · **T ข้อความ** — เลือกสี/ความหนาได้                                                        |
| **ย้อน / ล้าง**           | **ย้อน 1 ขั้น** (หรือ `Ctrl+Z`) · **ล้างที่เขียน** ลบหมดทั้งแผ่น                                                                                                  |
| **จิ้มหมุดได้เลย**        | กล่อง **จิ้มหมุดบนแผนที่** ใต้ฟอร์ม — จิ้มก่อนเก็บได้ในที่เดียว ไม่ต้องไปตามจิ้มทีหลัง (ซูม/หมุนได้เหมือนกัน)                                                     |
| **เอา / ไม่เอา**          | `Enter` เก็บเข้าคลัง · `→` ไม่เอา (ใบที่ไม่เอาจะไม่โผล่มาอีก)                                                                                                     |

**ปักหมุดอัตโนมัติ** — ValoLineups Pro บอกต้นทาง/ปลายทางของทุกใบมาเป็นชื่อโซนอยู่แล้ว
(`A Lobby → A Site`) เอามาจับคู่กับ `callouts.json` ที่เราวางตำแหน่งไว้เอง **ก็ได้หมุดโดยไม่ต้องจิ้ม**

| สถานะ                 | ป้ายในตาราง | ได้เท่าไหร่ (วัดกับ 6,027 ใบจริง) |
| --------------------- | ----------- | --------------------------------- |
| ได้ครบจุดยืน+ปลายทาง  | 📍          | **69.6%**                         |
| ได้แค่จุดยืน          | 📍½         | รวมเป็น **97.3%**                 |
| เดาไม่ได้ ต้องจิ้มเอง | —           | ที่เหลือ                          |

- **ไม่แน่ใจก็ไม่เดา** — ฝั่งไหนหาชื่อโซนไม่เจอจะปล่อยว่างไว้เฉยๆ เพราะหมุดผิดอันตรายกว่าไม่มีหมุด
  (กดดูแล้วไปยืนผิดที่ = ยิงพลาดทั้งลูก) ตรวจแล้วกับชื่อที่ตรงตัว 9,046 ชื่อ **จับผิดคู่ 0 ครั้ง**
- ในโหมดทีละใบ **หมุดที่เดาได้จะโชว์บนแผนที่ให้ดูก่อนกดเก็บ** (ขึ้นว่า "ปักให้อัตโนมัติ") ไม่ตรงก็คลิกจิ้มทับได้เลย
- อยากให้จับได้มากขึ้น: ไปวางชื่อโซนที่ยังขาดเพิ่มด้วย `tools/place_callouts.py` แล้วมันจะจับได้เองทันที
  (ที่จับไม่ได้ส่วนใหญ่คือชื่อย่อยที่เรายังไม่มี เช่น `A Generator`, `A Truck`, `B Logs`)

**เก็บหลายใบรวดเดียว** — ต่อรูปให้อัตโนมัติตามตั้งค่าจัดหน้าปัจจุบัน **ไม่ได้แต่ง** แล้วเก็บทีละใบ
เรียงกันไป (มีแถบความคืบหน้า + ปุ่มหยุด) จบแล้วสรุปให้ว่า `เก็บ 18 ใบ · ปักหมุดให้ 16 · ข้าม 2`

> ไฟล์ที่ได้ใบละราว **4-5 MB** ที่ความกว้าง 2560 — เก็บรวดเดียว 20 ใบ = ~100 MB
> ถ้าไม่อยากให้คลังบวมเร็ว ลด **⤢ ความกว้างไฟล์** เป็น 1920 ก่อนกดเก็บ

- **ที่เขียนไว้ผูกกับรูปแต่ละขั้น ไม่ใช่ผูกกับแผ่น** — เปลี่ยนคอลัมน์/ขนาด หรือลากย้าย/ย่อขยายทีหลัง
  สิ่งที่เขียนยังเกาะอยู่กับรูปนั้นและขยายตามไปด้วยเสมอ
- **ที่เขียนอยู่ชั้นบนสุดเสมอ** — ลากเขียนเลยขอบรูปไปทับรูปข้างๆ ได้ ไม่โดนรูปใบอื่นบัง
  (โปรแกรมวาดรูปให้ครบทุกใบก่อน แล้วค่อยวาดสิ่งที่เขียนทับทีเดียวทั้งแผ่น)
- กรอบไข่ปลากับจุดจับมุมเป็นแค่ตัวช่วยตอนจัดหน้า **ไม่ติดไปในไฟล์ที่เก็บเข้าคลัง**
- **ปุ่มบนแถบเครื่องมือเป็นไอคอนล้วน ไม่มีข้อความกำกับ** (แถบจะได้ไม่ยาว) — ชี้เมาส์ค้างที่ปุ่ม
  จะมีคำอธิบายขึ้นมาบอกว่าปุ่มไหนทำอะไร:
  `✥` ย้าย/ย่อขยาย · `✎` ปากกา · `╱` เส้นตรง · `↗` ลูกศร · `T` ข้อความ ·
  `↶` ย้อน 1 ขั้น · `⌫` ล้างที่เขียน · `🗑` ลบรูปที่เลือก · `⊕` คืนรูปที่ลบ ·
  `▦` คอลัมน์ · `↔` ช่องไฟ · `①` เลขกำกับ · `⤢` ความกว้างไฟล์ · `⊞` จัดเรียงใหม่
- ลบรูปแล้ว **เลขกำกับขั้นเรียงใหม่ให้เอง** (ลบใบ 3 จาก 5 ใบ → เหลือ 1-2-3-4 ไม่ใช่ 1-2-4-5)
  และจัดตารางใหม่ให้ไม่มีรูโหว่ ยกเว้นถ้าลากจัดหน้าเองไว้แล้วจะไม่ไปยุ่งกับที่จัดไว้
- เก็บแล้วติดแท็กสกิลให้เอง (Recon Bolt → `recon`) และจำว่าเอา/ไม่เอาใบไหนไปแล้วใน `browse.json`
  **ชุดเดียวกับเครื่องมือ Qt เดิม** กดข้ามในหน้าไหนอีกหน้าก็ไม่เอามาให้ดูซ้ำ
- **ValCompanion ไม่ได้บอกโซนต้นทาง/ปลายทาง** (ให้มาแค่รูปเดียว 1920×1080 + ลิงก์ YouTube)
  ใบจากเว็บนี้จึงปักหมุดอัตโนมัติให้ไม่ได้ ต้องจิ้มเอง — และจุด A/B/C ก็ต้องเดาจากชื่อ/คำอธิบาย
  (เดาได้ราวครึ่งหนึ่ง ที่เหลือปล่อยว่างให้เลือกเองในฟอร์ม)
- เดาหมุดให้ไม่ได้ก็ **จิ้มเองในกล่องจิ้มหมุดก่อนกดเก็บ** จิ้มแล้วจะบันทึกไปพร้อมกับรูปในคลิกเดียว
  (ไม่จิ้มก็เก็บได้ ค่อยไปจิ้มทีหลังในแท็บ `คลังของเรา`)
- **หมุนแผนที่แค่ภาพที่เห็น พิกัดที่เก็บไม่ขยับตาม** — จิ้มตอนหมุน 137° ซูม 3 เท่าอยู่ก็ยังได้
  พิกัดที่ถูกต้อง (ให้เบราว์เซอร์คิดเมทริกซ์ผกผันให้ ไม่ได้เขียนสูตรหมุนเอง)

**หน้าตาแก้เองได้ ไม่ต้องบิ้วโปรแกรมใหม่** — ไฟล์หน้าเว็บอยู่ที่ `assets/web/`
(`index.html` · `style.css` · `app.js` · `source.js` · `mapview.js`) อยู่**นอกตัว exe** แก้แล้วกด refresh เห็นผลทันที
สีทั้งหมดรวมไว้ที่ `:root` ใน `style.css` ที่เดียว เปลี่ยนธีมทั้งหน้าได้โดยไม่ต้องไล่แก้ทีละที่

- ไม่ใช้เฟรมเวิร์กเว็บใดๆ (ไม่มี Flask/React/npm) — ใช้ `http.server` ที่มากับ Python อยู่แล้ว
  กับ HTML/CSS/JS ล้วน จึงไม่มี dependency เพิ่มและไม่มีขั้นตอน build ให้ยุ่ง
- เปิดเฉพาะ `127.0.0.1` (เครื่องตัวเองเท่านั้น) + มี token สุ่มทุกครั้งที่เปิด เครื่องอื่นหรือ
  หน้าเว็บอื่นในเครื่องยิงคำสั่งเข้ามาลบไฟล์ไม่ได้
- ปิดเซิร์ฟเวอร์ด้วย **Ctrl+C** ที่หน้าต่างคอนโซลที่เปิดขึ้นมา

### โหลดมาทั้งกองแล้วคัด (ปุ่ม `คัดใบซ้ำ…`)

เพิ่มตัวละครใหม่แบบโหลดจากหน้า "หาไลน์อัพจากเว็บ" มาทีเดียวทุกแมพก็ได้ ไม่ต้องกรองก่อน — แล้วกด
**คัดใบซ้ำ…** (มุมขวาบนของแท็บคลัง) เลือกตัวละคร โปรแกรมจะจัดกลุ่มตาม **แมพ × ฝั่ง × สกิล × โซนที่สกิลไปตก**
(ข้อมูลจากเว็บต้นทาง ไม่ได้เดาจากชื่อไฟล์) แล้วโชว์ทีละกลุ่มเทียบรูปข้างกัน ใบที่แนะนำติดกรอบเขียวไว้ให้แล้ว
(★/เคยใช้ก่อน → ขั้นตอนน้อยกว่า → มีหมุดครบ)

| ปุ่ม | ทำอะไร |
| --- | --- |
| `1`–`9` | สลับเก็บ/ทิ้งใบนั้น |
| `Enter` | ยืนยันแล้วไปกลุ่มถัดไป |
| `0` | ทิ้งทั้งกลุ่ม |
| `Backspace` / `S` | กลับกลุ่มก่อน / ข้ามไว้ตัดสินทีหลัง |

- ตัวอย่างจริง: KAY/O 241 ใบ มีกลุ่มที่ต้องเลือกจริงแค่ **52 กลุ่ม** (ที่เหลือเป็นใบเดียวของเป้านั้นอยู่แล้ว)
- ปิดกลางทางได้ ความคืบหน้าจำไว้ · กดสรุปแล้ว **ย้ายใบที่ทิ้งเข้า .trash** (กู้คืนได้ · หมุด/แท็กถูกล้าง ·
  รวมคลังข้ามเครื่องแล้วไม่ฟื้นกลับมา) กลุ่มที่ยังไม่ตัดสินไม่ถูกแตะ
- ใบที่เหลือได้**แท็กสกิลจากเว็บ**ให้อัตโนมัติ (KAY/O: มีด / ลูกไฟ(ระเบิด) / แฟลช) — ใช้ตัวกรองสกิลในเกมได้ทันที
- ใบที่วางเข้าคลังเองไม่ถูกแตะ

## จัดการคลังแบบเดิม (หน้าต่าง Qt)

```bash
python tools/manage.py
```

หน้าต่างเดียวจบ — ซ้ายเป็นรูปย่อทั้งคลัง (กรองตามแมพ/ฝั่ง/จุด + ค้นหาจากชื่อ)
ขวาเป็นรูปใหญ่กับช่องแก้ไข

| ทำอะไร                           | ยังไง                                                                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **เพิ่ม**                        | ลากไฟล์มาวาง · **Ctrl+V** วางจากคลิปบอร์ด · ปุ่ม **+ เพิ่มรูป...**                                                             |
| **เปลี่ยนชื่อ / ย้าย / แก้โน้ต** | แก้ช่องในฟอร์ม แล้วกด **บันทึกการแก้ไข** (ทำพร้อมกันได้ในคลิกเดียว)                                                            |
| **ลบ**                           | ปุ่ม **ลบ** หรือกด **Delete** — มีถามยืนยันก่อน                                                                                |
| **จิ้มหมุด / ตั้งป้าย A-B-C**    | แผนที่อยู่ข้างรูปพรีวิวเลย ไม่ต้องเปิด `pin_lineups.py` แยก (ดูวิธีจิ้มที่หัวข้อ [หน้าแผนที่](#หน้าแผนที่-ชั้น-0))             |
| **ซูมดูรูป**                     | **หมุนลูกกลิ้งบนรูป** (ซูมอยู่ในกรอบเดิม ไม่เด้งหน้าต่างใหม่) · ลาก = เลื่อนดู · ดับเบิลคลิก = กลับไปพอดีกรอบ                  |
| **ติดสกิล / ⭐ / แท็ก**          | แถว **สกิล/แท็ก** ในฟอร์ม — ใช้กรองตอนเล่น ([รายละเอียด](#ตัวกรอง-เล่นหลายตัวละครหลายสกิล)) · ปุ่มขวาสุดเหมาทั้งชุดที่กรองอยู่ |
| **หมุนแผนที่**                   | แถบเลื่อนใต้แผนที่ — ปรับได้ทีละ 1° ตั้งแต่ 0-359 · ปุ่ม **⟳ 90°** กดทีละ 90 · ปุ่ม **รีเซ็ต** กลับ 0                          |

- แคปจอด้วย **Win+Shift+S** แล้ว **Ctrl+V** ได้เลย ไม่ต้องเซฟไฟล์ก่อน
- **หมุนลูกกลิ้งบนรูปเพื่อซูม** — ซูมอยู่ในกรอบเดิม ไม่เด้งหน้าต่างใหม่ จะได้เพ่งดูว่าในรูปยืน
  ตรงไหน/เล็งไปทางไหน แล้วคลิกแผนที่ข้างๆ ได้เลยโดยไม่ต้องปิดอะไรก่อน
  (ใช้ได้เหมือนกันในหน้าจิ้มหมุดและหน้าวางตำแหน่งชื่อโซน)
- **เส้นแบ่งลากได้ทั้งสองเส้น** — ระหว่างรายการรูปย่อกับแผงขวา และระหว่างรูปกับแผนที่ —
  ลากให้ฝั่งที่กำลังใช้งานใหญ่ขึ้นได้ตามใจ
- **แถบหมุนแผนที่** — รูปแมพที่เอามาเทียบจากที่อื่น (คลิปสอน เว็บอื่น) มักหันคนละทางและหมุนมา
  เป็นองศาไม่ลงตัว เลื่อนแถบให้หันเหมือนกันก่อนแล้วค่อยจิ้มหมุดจะเทียบง่ายกว่ามาก
  **หมุนแค่ภาพที่เห็น พิกัดที่เซฟไม่ขยับตาม** — หมุด ป้าย A/B/C และชื่อโซนหมุนตามภาพไปด้วย
  คลิกจิ้มหมุดตอนหมุนอยู่ก็ยังลงตำแหน่งถูก (โปรแกรมแปลงพิกัดกลับให้เอง) · จำมุมแยกต่อแมพ
  สลับรูปในแมพเดิมไม่ต้องตั้งใหม่
- **ลบ = ย้ายเข้า `.trash/`** ที่รากโปรเจกต์ ไม่ได้ลบถาวร ลากกลับมาเองได้
  (`.trash/` อยู่นอก `lineups/` ตัวสแกนจึงมองไม่เห็น)
- ชื่อซ้ำจะต่อท้ายเป็น `(2)` ให้เอง ไม่ทับของเดิม
- **ช่องโน้ต** — พิมพ์คำอธิบายสั้นๆ (เช่น "ชาร์จ 2 ขีด เด้ง 1") แล้วมันจะ**โชว์แทนชื่อไฟล์**บน
  จอที่สองเลย มีประโยชน์มากตอนสูตรจากจุดยืนเดียวกันเยอะๆ เพราะรูปจะหน้าตาคล้ายกันจนแยกจาก
  ชื่อไฟล์อย่างเดียวยาก — ลบข้อความในช่องจนว่างแล้วบันทึก จะกลับไปโชว์ชื่อไฟล์เหมือนเดิม

> **สำคัญ: อย่าย้าย/เปลี่ยนชื่อไฟล์เองใน File Explorer**
> ไลน์อัพหนึ่งตัวมีของพ่วงที่ผูกกับชื่อและที่อยู่อีก 4 อย่าง — ไฟล์ `.gif`, ไฟล์โน้ต `.txt`,
> หมุดใน `positions.json` และสถิติ `uses` ใน `last-view.json` โปรแกรมจัดการลากตามให้ครบ
> แต่ถ้าย้ายเองหมุดกับสถิติที่สะสมไว้จะหลุดหายเงียบๆ
>
> และควร **ปิดโปรแกรมหลักก่อนแก้ไข** เพราะมันเขียน `last-view.json` ทุกครั้งที่กดปุ่ม

## ต่อรูปขั้นตอน (ทำไลน์อัพใบเดียวที่ทำตามได้ครบ)

```bash
python tools/compose_lineup.py
```

ท่าหนึ่งมักต้องเห็นหลายขั้นถึงจะทำตามได้จริง — **ยืนตรงไหน → เล็งยังไง → ลูกไปทางไหน →
ผลลัพธ์** แต่จอที่สองโชว์ทีละรูป เครื่องมือนี้เอารูปแคปหลายใบมาต่อเป็น**รูปเดียว**แล้วเซฟ
เข้าคลังให้เลย โปรแกรมหลักจึงเห็นเป็นไลน์อัพใบเดียวตามปกติ (ผลลัพธ์เป็นไฟล์รูปธรรมดา)

**เป็นคนละโปรแกรมกับหน้าจัดการคลัง** เพราะทำงานกับ "รูปดิบที่ยังไม่เข้าคลัง" คนละชุดกัน

| ทำอะไร                   | ยังไง                                                                                              |
| ------------------------ | -------------------------------------------------------------------------------------------------- |
| **เอารูปดิบเข้ามา**      | เปิดโฟลเดอร์รูปแคป (หาให้เองตอนเปิดครั้งแรก) · ลากไฟล์/โฟลเดอร์มาวาง · **Ctrl+V** วางจากคลิปบอร์ด  |
| **คัดว่าจะเอาใบไหน**     | ดับเบิลคลิกรูป = ใส่เป็นขั้นถัดไป · เลือกหลายใบแล้วกด **เพิ่มที่เลือก →** · ใบที่ใช้แล้วมี ✓ กำกับ |
| **เรียงลำดับขั้น**       | ปุ่ม **▲ ขึ้น / ▼ ลง** ในรายการขั้นตอนทางขวา                                                       |
| **ใส่คำอธิบายแต่ละขั้น** | พิมพ์ในช่องใต้รายการ — โผล่เป็นแถบดำทับขอบล่างของช่องนั้น                                          |
| **วาดลูกศรชี้**          | กด **✎ วาดลูกศร** แล้วลากเมาส์บนตัวอย่าง — ลากในช่องไหนลูกศรลงช่องนั้น                             |
| **บันทึก**               | **บันทึกเข้าคลัง** (เลือกแมพ/ฝั่ง/จุด/ตัวละคร + ตั้งชื่อ) หรือ **บันทึกเป็นไฟล์…** เอาไปใช้ที่อื่น |

- **จัดกลุ่มตามเวลาถ่ายให้เอง** — รูปที่กดแคปไล่กันภายในไม่กี่นาทีถือเป็นท่าเดียวกัน เปิดมา
  จะเลือกกลุ่มล่าสุดไว้ให้ (คือชุดที่เพิ่งซ้อมเสร็จ) กด **ใส่ทั้งกลุ่มเป็นขั้นตอน** ทีเดียวจบ
- **จำนวนคอลัมน์เลือกให้เอง** — 4 ขั้นได้ 2×2, 3 ขั้นได้บน 2 ล่าง 1 กึ่งกลาง ปรับเองได้ถ้าไม่ชอบ
- ลูกศรเก็บเป็นสัดส่วนของช่อง **เปลี่ยนคอลัมน์/ขนาดทีหลังลูกศรยังชี้จุดเดิม**
- เลขกำกับขั้นใช้สีเหลืองชุดเดียวกับเลขหมุดในโปรแกรมหลัก เพื่อให้รู้สึกเป็นระบบเดียวกัน
- จำโฟลเดอร์ล่าสุด/ค่าที่ตั้งไว้ใน `compose.json` เปิดครั้งหน้าไม่ต้องตั้งใหม่

> แทน** — ตัวนั้นดึงได้ 2 เว็บ มีโหมดตารางคัดทีละหลายใบ กรองด้วยการจิ้มแผนที่ และปักหมุด
> ให้อัตโนมัติ · หน้าต่าง Qt ตัวนี้เก็บไว้เป็นของสำรอง ดึงเฉพาะ ValoLineups Pro แบบทีละใบ

ดึงรายการจาก **ValoLineups Pro** (ตัวแรกในตารางข้างบน) มาให้ดู**ทีละใบ** — รูปที่เห็นคือรูป
ที่จะได้จริง (ต่อทุกขั้นเป็นใบเดียวให้แล้ว) **ชอบกด `Enter` ไม่ชอบกด `→` จบแค่นั้น**
ใบที่กดเอาจะถูกเก็บเข้าคลังให้เลยพร้อมติดแท็กสกิลให้อัตโนมัติ

| ทำอะไร                      | ยังไง                                                                 |
| --------------------------- | --------------------------------------------------------------------- |
| **เลือกชุดที่จะดู**         | ตัวกรองด้านบน — ตัวละคร / แมพ / ฝั่ง / จุด / สกิล (เริ่มที่ sova ให้) |
| **เอา**                     | ปุ่ม **✓ เอาเข้าคลัง** หรือกด **Enter**                               |
| **ไม่เอา**                  | ปุ่ม **✗ ไม่เอา** หรือกด **→** (หรือ Space) — ใบนั้นจะไม่โผล่มาอีก    |
| **ย้อนดูใบก่อนหน้า**        | ปุ่ม **← ย้อน** หรือกดปุ่ม **←**                                      |
| **เปลี่ยนชื่อ/จุดก่อนเก็บ** | ช่องใต้รูป — จุดจะเดาให้จากข้อมูลเว็บ ยกเว้น MID ที่ต้องเลือกเอง      |

- **โหลดรูปล่วงหน้าให้ตลอด** ระหว่างดูใบนี้มันโหลดใบถัดๆ ไปรอไว้แล้ว กดข้ามรัวๆ ได้ไม่ต้องรอ
- **จำว่าเคยตัดสินใบไหนไปแล้ว** (`browse.json`) ปิดแล้วเปิดใหม่จะต่อจากที่ค้างไว้ ไม่วนซ้ำ —
  **ใช้ไฟล์เดียวกับหน้าเว็บ** กดข้ามในหน้าไหนอีกหน้าก็ไม่เอามาให้ดูซ้ำ (รหัสในไฟล์เก็บเป็น
  `vlp:1234` / `vc:5678` เพราะเลขของแต่ละเว็บชนกันได้ — ของเก่าที่เป็นเลขล้วนแปลงให้อัตโนมัติ)
- ติดแท็กสกิลให้เอง (Recon Bolt → `recon`, Snake Bite → `molly` ฯลฯ) ใช้กรองตอนเล่นได้ทันที
- เก็บจากหน้าต่างนี้แล้ว **ยังต้องไปจิ้มหมุดเองในหน้าจัดการคลัง** (หน้าเว็บปักให้อัตโนมัติได้ ตัวนี้ยังไม่ได้ทำ)
- แมพที่เว็บมีแต่คลังเราไม่มี (แมพเก่าที่ถอดออกจากเกมแล้ว) จะขึ้นเตือนไว้ว่าเก็บไม่ได้
- รูปที่โหลดมาพักไว้ใน `.cache/` ลบทิ้งได้ตลอด ไม่กระทบของที่เก็บเข้าคลังไปแล้ว

> รูปเป็นของเว็บต้นทาง/ชุมชนที่ทำไว้ — โหลดมาไว้ซ้อมเองในเครื่อง ไม่ได้เอาไปแจกต่อ
> และตัวโปรแกรมหน่วงจังหวะโหลดไว้แล้ว ไม่ยิงถี่ใส่เซิร์ฟเวอร์เขา

## หน้าแผนที่ (ชั้น 0)

**เปิดโปรแกรมมาจะอยู่หน้านี้เลย** (เปลี่ยนได้ที่ `display: start_on_map` ใน `config.yaml`)
หรือกด **Numpad /** สลับเข้า/ออกเมื่อไหร่ก็ได้ — ได้แผนที่พร้อมหมุดจุดยืนที่มีเลขกำกับ:

```
ASCENT   │   ตั้งรับ   │   แผนที่   │   7 จุดยืน   │   ยังไม่จิ้ม 6 รูป
```

**เลข 1-9 เปลี่ยนความหมายสองจังหวะ — กดตามเลขที่เห็นบนจอตอนนั้นได้เลย ถูกเสมอ:**

```
ยังไม่ได้เลือกหมุด  →  เลข = หมุด      (จุดที่เรายืน · วงกลมพื้นเข้ม เลขสีประจำตัว)
เลือกหมุดแล้ว       →  เลข = ปลายทาง  (จุดที่ลูกไปลง · วงกลมเหลืองทึบ เลขสีเข้ม)
```

- **ทุกหมุดมีเส้นจางลากไปเป้าตลอดเวลา** เห็นได้เลยว่าแต่ละจุดยิงไปทางไหนโดยไม่ต้องกดเลือกก่อน
- **กดเลขหมุด** → หมุดนั้นสว่างเป็นสีเหลือง เส้นของมันเข้มขึ้น **และปลายเส้นทุกเส้นขึ้นเลขกำกับ**
- **กดเลขปลายทาง** → เปิดรูปนั้นเต็มจอทันที — เลือกจากแผนที่ได้เลยว่า _จะยิงไปจุดไหน_
  โดยไม่ต้องไล่ดูรูปทีละใบก่อน (หัวจอจะบอกด้วยว่าตอนนี้กดเลขได้ถึงเลขไหน)
- **Numpad .** → ถอยกลับไปเลือกหมุดใหม่ (ตอนเลือกหมุดค้างอยู่ เลขจะเป็นปลายทางหมด
  สลับไปหมุดอื่นตรงๆ ไม่ได้ ต้องถอยก่อน) · ไม่ได้เลือกหมุดอยู่ ปุ่มนี้ = เปลี่ยนหน้าหมุด
- **อยากดูทุกใบของหมุดนั้นรวมกัน** → เลือกปลายทางใบไหนก็ได้ แล้วกด **Numpad 5** ถอยซูมออก
  จะได้กริดที่กรองเหลือเฉพาะสูตรจากจุดยืนนั้น (เลขบนรูปในกริดก็กดเลือกได้เหมือนกัน)
- **Numpad /** อีกที → ออกจากแผนที่ ล้างตัวกรอง กลับไปเห็นทั้งครึ่งตามเดิม
- `×3` ใต้หมุด = จุดนั้นมี 3 สูตร · หมุดเกิน 9 อันใช้ **Numpad .** เปลี่ยนหน้า
- **+/− และ 0 ยังเปลี่ยนแมพ/สลับฝั่งได้ตามปกติ** ขณะอยู่บนแผนที่
- ป้ายตัวอักษร **A/B/C สีฟ้า** กำกับจุดยิงให้เอง — รูปแผนที่ดิบไม่มีตัวอักษรนี้มาให้ (มีแค่สี
  แต้มบอกว่าเป็นห้องเฉยๆ) **เส้นประ+จาง** = ยังไม่มีใครตั้งเอง เดาจากค่าเฉลี่ยจุด "to" ของสูตร
  ในจุดนั้น (อาจเพี้ยนถ้าจุดที่คลิกตอนจิ้มแต่ละสูตรกระจายกันมาก) · **ทึบชัด** = ตั้งเองแล้วผ่าน
  ปุ่ม "ตั้งป้าย" ใน `tools/pin_lineups.py` (ดูหัวข้อล่าง) แม่นกว่าเพราะเป็นจุดที่ตั้งใจวางจริงๆ

### ตั้งค่าครั้งแรก (ทำ 2 ขั้น)

โฟลเดอร์บอกได้แค่ว่า _ยิงไปจุดไหน_ ไม่ได้บอกว่า _เรายืนตรงไหน_ ข้อมูลจุดยืนจึงต้องจิ้มเอง

```bash
python tools/fetch_maps.py
```

โหลดรูปแผนที่ทางการจาก valorant-api.com (ฟรี ไม่ต้องล็อกอิน) เก็บที่ `assets/maps/`

```bash
python tools/pin_lineups.py
python tools/pin_lineups.py --map ascent    # เปิดมาแล้วกรองแมพนี้ไว้ก่อน
```

**ซ้ายเป็นลิสต์รูปย่อทั้งคลัง** กรองตามแมพ/ฝั่ง/จุด + ค้นหาจากชื่อได้ — รูปที่จิ้มแล้วมี
`✓` นำหน้าชื่อ **เลือกรูปไหนก็ได้จากตรงนี้เพื่อไปจิ้ม** ไม่ต้องไล่ทีละรูปตามลำดับ
กลางเป็นรูปสูตร ขวาเป็นแผนที่ — **คลิกที่ 1 = จุดที่เรายืน · คลิกที่ 2 = จุดที่ลูกลง**
แล้วเด้งไปรูปถัดไปที่ยังไม่จิ้มเอง เซฟลง `positions.json` ทุกรูป (ปิดกลางคันไม่เสียงาน)

- คลิกใกล้หมุดฟ้าที่มีอยู่แล้ว = **สแนปเข้าหมุดเดิม** หลายสูตรที่ยืนจุดเดียวกันจะรวมเป็นหมุดเดียว
  (ควรทำ ไม่งั้นแมพเดียวจะมีหมุดเกิน 9 จนกดเลขเลือกไม่ครบ)
- **ตั้งผิดแก้ได้เสมอ**: เลือกรูปนั้นจากลิสต์ (เลิกติ๊ก "เฉพาะที่ยังไม่จิ้ม" ถ้ามันถูกซ่อนไปแล้ว)
  แล้วกด **ลบหมุดของรูปนี้** มุมขวาบน หรือกด `Delete` — ลบแค่พิกัดหมุด ไม่ได้ลบรูป จิ้มใหม่ได้ทันที
- `Space` ข้ามไปรูปถัดไปที่ยังไม่จิ้ม · `Backspace` ย้อน/ยกเลิกคลิกแรก · `Esc` ออก

**ตั้งป้าย A/B/C เอง (ถ้าค่าเฉลี่ยอัตโนมัติเพี้ยน)**: เหนือรูปสูตรมีปุ่ม **"ตั้งป้าย A"** /
**"ตั้งป้าย B"** ให้ตามจุดที่มีในแมพนั้น — กดปุ่ม แล้วคลิกตำแหน่งจริงบนแผนที่ 1 ที เป็นอัน
เสร็จ (กดปุ่มเดิมซ้ำ = ยกเลิกโหมดโดยไม่วาง) ป้ายจะเปลี่ยนจากเส้นประจางเป็นทึบชัดทันที
กด **"ล้าง"** ข้างปุ่มนั้นถ้าอยากกลับไปใช้ค่าเฉลี่ยอัตโนมัติ

**ตั้งครั้งเดียวใช้ได้ทั้งบุกและตั้งรับ** — จุด A/B/C อยู่ที่เดิมไม่ว่าจะฝั่งไหน ป้ายที่ตั้งเอง
จึงไม่ผูกกับฝั่ง ไม่ต้องตั้งซ้ำสองรอบ (ส่วนค่าเฉลี่ยอัตโนมัติที่ยังไม่ได้ตั้งเอง คำนวณแยกราย
ฝั่งอยู่ เพราะอิงจุด "to" ของสูตรฝั่งนั้นๆ)

**ไม่ต้องจิ้มให้ครบทีเดียว** รูปที่ยังไม่จิ้มใช้งานได้เหมือนเดิมทุกอย่าง แค่ไม่โผล่บนแผนที่
จิ้มเพิ่มระหว่างเปิดโปรแกรมอยู่ได้เลย ไม่ต้องรีสตาร์ต

> พิกัดหมุดเป็นสัดส่วนของรูปแผนที่ (0..1) ถ้าเปลี่ยนไปใช้รูปแผนที่คนละอัน หมุดจะเพี้ยนทั้งหมด


เลือกชื่อจากลิสต์ซ้าย (✓ = วางแล้ว, พิมพ์ค้นหาได้ถ้ารายชื่อยาว) แล้ว **คลิก 1 ทีบนแผนที่กลาง**
เพื่อวางตำแหน่ง เสร็จแล้วเด้งไปชื่อถัดไปที่ยังไม่ได้วางให้เอง — ชื่อที่ API ให้มาไม่ตรงกับที่จอเกมโชว์เป๊ะทุกตัวก็แก้ใน
ช่องข้อความได้เลย ไม่ต้องแก้ไฟล์เอง

**ขวาสุดมีรูปอ้างอิงจาก tracker.gg** (มีชื่อโซน + สีแบ่งเขตกำกับไว้พร้อมแล้ว) ให้ดูว่าแต่ละชื่อ
อยู่ตรงไหนของแมพ ไม่ต้องนึกจากความจำ ดาวน์โหลดครั้งแรกด้วย `fetch_callout_reference.py`
(เก็บแยกไว้ที่ `assets/callout_reference/` **ไม่ใช่รูปแผนที่จริง** ไม่กระทบพิกัดหมุดใดๆ ทั้งสิ้น
ใช้ดูอ้างอิงเฉยๆ) — รูปอ้างอิงมักหมุนคนละมุมกับแผนที่ของเรา หมุนฝั่งไหนก็ได้ให้ตรงกัน:
**"หมุนรูปอ้างอิง ⟳"** (หรือ `R`) หมุนรูป tracker.gg · **"หมุนแผนที่หลัก ⟳"** (หรือ `Shift+R`)
หมุนแผนที่ของเราเอง — คลิกวางได้ตามปกติแม้หมุนอยู่ พิกัดที่เซฟยังถูกต้องเหมือนเดิมทุกประการ
จะได้ไม่ต้องนึกหมุนในหัวเทียบตำแหน่งจนเวียนหัว

> พิกัดดิบจาก API เชื่อไม่ได้ (ปัญหาเดียวกับป้าย A/B/C ด้านบน — บางแมพหมุนแกนไปจากรูป
> minimap) จึงดึงมาแค่ "ชื่อ" อัตโนมัติ ส่วน "ตำแหน่ง" ต้องคลิกวางเองทีละชื่อเสมอ

#### วางตำแหน่งให้อัตโนมัติ (ไม่ต้องคลิกเองทีละชื่อ)

```bash
python tools/auto_place_callouts.py              # ทุกแมพ
python tools/auto_place_callouts.py --map bind   # แมพเดียว
```

รูปอ้างอิงของ tracker.gg **มีชื่อโซนพิมพ์กำกับไว้ตรงตำแหน่งจริงอยู่แล้ว** ถ้ารู้ว่าต้องหมุน/ย่อ/
เลื่อนรูปนั้นเท่าไหร่ถึงจะทับกับรูปแผนที่ของเรา ก็แปลงตำแหน่งป้ายทุกอันมาเป็นพิกัดของเราได้
ทีเดียวทั้งแมพ เครื่องมือนี้ทำ 3 ขั้นให้เอง:

1. **หามุมหมุนเอง** — เอา "เงาของแมพ" มาเทียบกันตรงๆ ลองหมุน 0/90/180/270° แล้วดูว่ามุมไหน
   ทับกันมากสุด (มุมที่ถูกได้ 0.81-1.00 มุมที่ผิดได้แค่ ~0.3-0.5 แยกออกชัดมาก) — แต่ละแมพหมุน
   คนละมุมกันจริงๆ เช่น bind 0° · icebox 90° · summit 180° · ascent 270°
2. **อ่านป้ายในรูปอ้างอิงด้วย OCR** — Windows OCR คืนกรอบของข้อความมาด้วย จึงรู้ตำแหน่งของแต่ละ
   ป้าย · **อ่านหลายขนาดแล้วรวมผล** เพราะแต่ละขนาดอ่านได้คนละชุด (ผังโซน summit: ขยาย 4 เท่า
   อ่านได้ 18 ป้าย · 5 เท่าได้เพิ่มอีก 2 · 8 เท่าถึงจะอ่าน MID FOUNTAIN ถูก) แล้วเอาค่ากลาง
   ของทุกรอบเป็นตำแหน่งจริง
3. **จับคู่ชื่อ** กับรายชื่อโซนที่รู้จัก — ตัวเดียวกับที่แอปหลักใช้ตอนเล่นจริง จึงไม่สนลำดับคำ
   ด้วย (ผังเขียน `A LOBBY` ส่วนที่เก็บไว้คือ `Lobby A`) และถ้าคล้ายสองชื่อพอๆ กันจะไม่เดา

**ไม่แตะชื่อที่วางตำแหน่งเองไว้แล้ว** (ของที่คลิกเองแม่นกว่าเสมอ) — ถ้าอยากให้ทับด้วยต้องสั่ง
`--overwrite` เอง

> **ความแม่นที่วัดได้จริง**: เทียบกับจุดที่วางเองไว้ก่อนแล้ว ห่างเฉลี่ย **1.5-3%** ของความกว้าง
> แผนที่ — พอสำหรับงานนี้เพราะชื่อโซนกินพื้นที่กว้างกว่านั้นมาก **แต่ควรเปิด `place_callouts.py`
> ดูสักรอบ** จะเห็นจุดที่วางให้ทั้งหมด อันไหนเพี้ยนคลิกแก้ได้ทันที
>
> ชื่อที่ OCR อ่านขาด/อ่านแล้วคล้ายหลายชื่อจนไม่กล้าเดา จะถูกข้ามไว้ให้คลิกวางเอง (ตอนนี้
> เหลือ 10 ชื่อจาก 300 ทั้งหมด)

**รูปอ้างอิงเอามาจากที่อื่นก็ได้** — `assets/callout_reference/<แมพ>.png` เป็นแค่ไฟล์รูป ใครจะ
เอาผังโซนจากเว็บไหนมาวางทับก็ได้ (tracker.gg ยังไม่มีผังของ summit จึงต้องหามาเอง) รองรับทั้ง
รูปพื้นหลังโปร่งใสและ **รูปที่มีฉากหลังทึบ** (เช่นภาพที่แคปมาจากเว็บ) — กรณีหลังจะหาเงาแมพจาก
ความสว่างแทนช่องอัลฟา และตัดกล่องชื่อโซนออกจากเงาให้เอง ไม่งั้นกรอบจะกว้างเกินจริงจนทาบเพี้ยน

### หาหมุดจากชื่อโซนอัตโนมัติ (OCR)

วางชื่อโซนไว้ครบแล้ว (หัวข้อบน) ก็ใช้ปุ่มนี้ให้โปรแกรม**อ่านชื่อเองแล้วชี้ไปหมุดที่ใกล้ที่สุด
ให้เลย** ไม่ต้องเปิดแผนที่ไปไล่หาด้วยตาเอง:

1. กด **Insert** ปุ่มเดียว กลางเกม ไม่ต้องแตะเมาส์ ไม่ต้อง Win+Shift+S
   (ใช้ได้ทุกหน้า ทั้งหน้าแผนที่และหน้ากริด)
2. โปรแกรม**แคปมุมซ้ายบนของจอเกมเอง** (จอที่ไม่ใช่จอที่หน้าต่างโปรแกรมอยู่) — กรอบเริ่มต้น
   กว้าง 35% x 50% ของจอ ครอบมินิแมพกับป้ายชื่อโซนใต้มินิแมพไว้แล้ว ไม่ต้องตั้งอะไรก่อนใช้
3. โปรแกรมอ่านตัวหนังสือจากรูปที่แคป เทียบกับชื่อโซนที่วางตำแหน่งไว้แล้วของแมพปัจจุบัน — **ค้นหา
   หมุดข้ามทั้งบุกและตั้งรับ** (ไม่ยึดว่าตอนนี้เซ็ตฝั่งไหนไว้) แล้ว**เข้าหน้าแผนที่พร้อมไฮไลต์หมุด
   ที่ใกล้ชื่อนั้นที่สุดให้เอง** (สลับฝั่งให้ตรงกับหมุดที่เจอด้วย) — เห็นหมุดข้างเคียงทั้งหมดในย่าน
   เดียวกันทันที กด**เลขเดิมซ้ำ**เพื่อยืนยันเข้าไปดูสูตร หรือกดเลขอื่นถ้าหมุดที่ใช่จริงๆ อยู่ใกล้ๆ
   กัน (ชื่อโซนหนึ่งชื่ออาจมีหลายหมุดซ้อนกันอยู่)

ทุกครั้งที่กด จะขึ้นข้อความบอกว่า**จับคู่ชื่อ/ฝั่งอะไรไป** เสมอ (เช่น `Lobby A → บุก`) แม้ตอน
สำเร็จก็ตาม — เพราะฟีเจอร์นี้พึ่ง OCR + จับคู่ชื่อคล้ายๆ กัน ไม่ได้แม่น 100% เหมือนปุ่มอื่นในแอป
เห็นข้อความนี้แล้วเช็คได้ทันทีว่าตรงกับจุดที่ยืนจริงไหม

**ไม่เดามั่วเด็ดขาด** — อ่านไม่ออก/แคปจอไม่ติด/ไม่มีชื่อไหนตรงพอ/แมพนี้ยังไม่มีหมุดเลย
ล้วนขึ้นข้อความบอกตรงๆ แทนที่จะกระโดดไปมั่วๆ

ในกรอบที่แคปมามีตัวหนังสืออื่นติดมาด้วยเป็นปกติ (เลขเวลา สกอร์ ชื่ออื่นบนมินิแมพ) — โปรแกรม
อ่านแยกเป็น**รายบรรทัด**แล้วเลือกบรรทัดที่คล้ายชื่อโซนที่สุดเอง บรรทัดขยะตกไปเองเพราะคะแนน
ความคล้ายต่ำเกินเกณฑ์ ไม่ต้องแคปให้พอดีป้ายเป๊ะๆ

### โหมดตามตัว (F9)

ปุ่ม Insert ข้างบนต้อง**กดเองทุกครั้ง** — โหมดนี้คือให้โปรแกรมกดให้เองเรื่อยๆ **เดินไปโซนไหน
หน้าแผนที่ก็ตามไปวงพื้นที่ตรงนั้นให้** (วงประแดง + ชื่อโซนกำกับ) พออยากใช้จริงค่อยกดเลขหมุด

**วงไว้เฉยๆ ไม่เลือกหมุดให้** — ชื่อโซนหนึ่งชื่อมีหลายหมุดอยู่ข้างในเป็นเรื่องปกติ (จุดอ้างอิงมี
จุดเดียวต่อชื่อ) ถ้ามันเลือกหมุดให้เลยก็เท่ากับเดาแทนเรา แถมพอเลือกแล้วเลข 1-9 จะกลายเป็น
"ปลายทาง" ทันที อยากกดหมุดอื่นต้องกด `Numpad .` ถอยออกมาก่อนทุกครั้ง — วงไว้แทนแล้วเลข 1-9
ยังแปลว่า "หมุด" ตลอดเวลา กดตัวที่จะใช้ได้เลยเหมือนตอนไม่ได้เปิดโหมดนี้

กด **F9** ครั้งเดียวตอนเริ่มเกม (หัวจอจะขึ้นว่า `ตามตัวอยู่ (F9 ปิด)`) — ใช้กรอบแคปเดียวกับ
ปุ่ม Insert ทุกอย่าง ตั้งค่าแยกไม่ต้อง

**สิ่งที่ทำให้มันไม่กวน** (สำคัญกว่าตัวฟีเจอร์เอง):

| กติกา                                           | ทำไม                                                                                                                                                                                                                                       |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **กดเลือกหมุดเมื่อไหร่ จอหยุดนิ่งทันที**        | กดเลขเลือกหมุด = กำลังจะใช้ไลน์อัพใบนั้นแล้ว ถ้าปล่อยให้มันอัปเดตต่อ จอจะเลื่อนหนีตอนกำลังเล็ง · ยืนอยู่จุดเดิมนานแค่ไหนก็ไม่โดนขยับ                                                                                                       |
| **เดินออกจากโซนนั้นเมื่อไหร่ = ตามต่อให้เอง**   | ออกจากโซนที่เพิ่งเลือกไลน์อัพไว้ = ใช้ใบนั้นเสร็จแล้ว ไม่ใช่การแย่งจอกลางเล็งอีกต่อไป — **ไม่ต้องกด Numpad . ถอยออกมาเองก่อนเดินต่อ** (กดกลางเกมจริงไม่ทัน) · อยากได้แบบเดิมตั้ง `auto` → `resume_on_move: false`                          |
| ซูมรูปอยู่ / อยู่หน้ารายการรูป ก็ไม่ขยับ        | เหตุผลเดียวกัน — และเด้งกลับมาหน้าแผนที่เองเหมือนกันเมื่อย้ายโซน โดยขอให้อ่านโซนใหม่ได้ติดกัน 3 ครั้ง (`resume_confirm`) ไม่ใช่ 2 เพราะยืนคร่อมรอยต่อสองโซนแล้ว OCR สลับไปมา ตอนตามเฉยๆ แค่วงขยับ แต่ตอนนี้แปลว่าเด้งออกจากรูปที่กำลังเล็ง |
| **ขนาดวงไม่ตายตัว**                             | วงให้ครอบ "กลุ่ม" หมุดที่อยู่ในโซนนั้น (หมุดที่ไกลไม่เกิน 2 เท่าของตัวที่ใกล้ที่สุด) เพราะโซนอย่าง A Lobby กับ A Site กว้างคนละเรื่อง วงเท่ากันหมดจะกินโซนข้างๆ ไปด้วยหรือไม่ก็เล็กจนไม่ครอบหมุดที่ควรเห็น                                 |
| **ต้องอ่านได้ชื่อเดิมติดกัน 2 ครั้งถึงจะเชื่อ** | OCR อ่านเพี้ยนครั้งเดียวแล้วกระโดดไปคนละมุมแมพกลางรอบ คือสิ่งที่แย่ที่สุดที่ฟีเจอร์นี้ทำได้                                                                                                                                                |
| อยู่โซนเดิม = ไม่วาดใหม่ ไม่ขึ้นข้อความ         | เดินวนอยู่ในโซนเดิมเป็นเรื่องปกติ ไม่ใช่เหตุการณ์                                                                                                                                                                                          |
| อ่านไม่ออก = เงียบ                              | ต่างจากปุ่ม Insert ที่ต้องบอกทุกครั้งเพราะผู้ใช้กดเอง — อันนี้ทำงานทุกวินาที เตือนทุกครั้งคือสแปม                                                                                                                                          |
| **แคปได้ภาพว่าง 5 ครั้งติด = ปิดโหมดให้เอง**    | เกมตั้งเป็นเต็มจอแบบผูกขาดจะแคปได้ภาพดำ บอกตรงๆ แล้วปิด ดีกว่าวนแคปภาพดำทิ้งทั้งเกม (แก้ด้วยการตั้งเกมเป็น Windowed Fullscreen)                                                                                                            |

**ไม่เดาว่าเล่นแมพไหนอยู่** — ยังต้องกด `Numpad +` เลือกแมพเองเหมือนเดิม เพราะชื่อโซนที่เจอบ่อย
ที่สุดใช้ร่วมกันหลายแมพมาก (`Attacker Spawn`/`Defender Spawn` มีทั้ง 13 แมพ · `A Site`/`B Site`
มี 12 แมพ) เดาแล้วสลับแมพผิดกลางรอบแย่กว่ากดเอง 1 ครั้งต่อเกม

**กินเครื่องแค่ไหน** — วัดบนเครื่องนี้: แคปจอ ~5 ms (เธรดหลัก) + OCR ~17 ms (เธรดแยก) ต่อรอบ
ที่รอบละ 1 วินาที = ราว 2% ของซีพียู · ปรับ `interval_ms` / `confirm` / `resume_on_move` /
`resume_confirm` ได้ใน `config.yaml` → `auto`

> **โหมดนี้อ่านจอตัวเองอย่างเดียว** ไม่อ่านหน่วยความจำเกม ไม่ฉีดโค้ดเข้าโปรเซสเกม ไม่ส่งปุ่มกลับ
> เข้าเกม และโชว์บนจอที่สองในหน้าต่างของตัวเอง ไม่ได้ซ้อนทับจอเกม — สิ่งที่ได้คือ**โน้ตของตัวเอง**
> ที่ถูกเรียกด้วยชื่อโซนที่มองเห็นอยู่บนจอเราอยู่แล้ว ไม่ใช่ข้อมูลที่เรามองไม่เห็น
> (เป็นความสามารถเดียวกับปุ่ม Insert ที่มีอยู่แล้ว แค่เรียกถี่ขึ้น)

จะเซฟภาพที่แคปได้เป็น `capture-test.png` ข้างๆ โปรแกรมให้เปิดดูเอง พร้อมพิมพ์ทุกบรรทัดที่ OCR
อ่านได้และบอกว่าจะเลือกชื่อโซนไหน

อยากบีบกรอบให้เหลือเฉพาะป้ายชื่อโซน (อ่านไวขึ้น แม่นขึ้น) เปิด **"เลือกกรอบแคปชื่อโซน"** แล้ว
ลากกรอบเอาเอง — มีปุ่ม "ทดสอบอ่าน" ให้เช็คทันทีว่าอ่านได้ตรงไหม กดบันทึกแล้วใช้ได้เลยไม่ต้อง
รีสตาร์ตแอปหลัก (เก็บลง `capture.json`)

> **ถ้าได้ภาพดำ** แปลว่าเกมตั้งเป็นเต็มจอแบบผูกขาด (Fullscreen) ซึ่งวิธีแคปแบบนี้เข้าไม่ถึง —
> ตั้งในเกมเป็น **Windowed Fullscreen** แล้วลองใหม่ · ระหว่างนี้ยังใช้วิธีเดิมได้ทุกอย่าง:
> แคปเองด้วย **Win+Shift+S** แล้วกด **Insert** โปรแกรมจะรู้เองว่าแคปจอไม่ติดแล้วหยิบรูปจาก
> คลิปบอร์ดมาใช้แทน (ขึ้นข้อความต่อท้ายว่า "จากคลิปบอร์ด" ให้เห็นด้วย)

> ชื่อโซนหนึ่งชื่อมักครอบพื้นที่กว้าง (ไม่ใช่จุดเดียว) จุดอ้างอิงที่ปักไว้ตอน `place_callouts.py`
> จึงเป็น "จุดเริ่มต้นที่ใกล้" ไม่ใช่ "ตรงเป๊ะเสมอ" — ถ้ายืนอยู่ขอบโซนหรือมีหลายหมุดซ้อนกันอยู่ใกล้ๆ
> หมุดที่ไฮไลต์ให้อาจไม่ใช่หมุดที่ตั้งใจเป๊ะ แต่เพราะเข้าหน้าแผนที่ (ไม่ใช่กระโดดเข้ากริดตรงๆ)
> จึงเห็นหมุดข้างเคียงทั้งหมดพร้อมกันอยู่แล้ว เลือกหมุดที่ใช่จริงๆ เองได้ทันทีโดยไม่ต้องกดอะไรเพิ่ม

> **ลำดับคำไม่ตรงกันไม่เป็นไร** — จอเกมโชว์ "Lobby A" แต่ชื่อที่ดึงมาจาก API เก็บเป็น "A Lobby"
> ระบบเทียบทั้งแบบตรงๆ และแบบ**เรียงคำใหม่ก่อนเทียบ** แล้วเอาค่าที่ดีกว่า จึงรู้ว่าเป็นชื่อเดียวกัน
> โดยที่กติกา "คล้ายสองชื่อพอๆ กันจะไม่เดา" ยังทำงานเหมือนเดิม ไม่ต้องไปแก้ชื่อให้ตรงกับจอเกมเอง
>
> (วัดกับข้อมูลจริงทั้ง 13 แมพ ทุกชื่อที่วางตำแหน่งไว้ ลองทั้งสองลำดับคำ รวม 538 กรณี —
> เทียบตรงๆ อย่างเดียวผ่าน 74.9% เพิ่มแบบเรียงคำแล้วผ่าน **100%** · ก่อนแก้จุดนี้ ยืนที่ Lobby A
> แล้วกดปุ่มจริงๆ ได้ "ไม่รู้จักชื่อนี้" เพราะ "A Lobby" กับ "B Lobby" ได้คะแนนเท่ากันเป๊ะ)

> **จับคู่ไม่ได้จะบอกด้วยว่าอ่านได้ว่าอะไร** เช่น `อ่านได้ "Lobby A" แต่ไม่มีชื่อไหนตรงพอ
(ใกล้สุด: A Lobby)` — เห็นทันทีว่าพังตรงไหน (กรอบที่แคปผิด / OCR อ่านเพี้ยน / ชื่อที่เก็บไว้
> ไม่ตรง) ไม่ต้องเดาเอง

ใช้ **Windows OCR ที่ติดมากับเครื่องอยู่แล้ว** (ตัวเดียวกับที่ Snipping Tool ใช้ตอน "คัดลอก
ข้อความจากรูป") ไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องต่อเน็ต — แต่ **ต้องรันด้วย Python 3.12** (ดู
คำเตือนหัวข้อติดตั้งด้านบน) ไม่งั้นปุ่มนี้จะใช้ไม่ได้ (ส่วนอื่นของโปรแกรมไม่กระทบ)

ทดสอบว่า OCR ใช้งานได้ไหมโดยไม่ต้องเล่นเกม:

```bash
.venv\Scripts\python.exe -m lineupmaster --check-ocr
```

> **ทำไมไม่ใช้ Numpad**: numpad เต็มแล้ว — บนหน้าแผนที่ เลข **1-9 ถูกใช้เลือกหมุดทั้งหมด**
> (รวม 4/5/6) ส่วน `0 + - . / *` ก็มีหน้าที่อยู่แล้ว ไม่เหลือปุ่มไหนว่างพร้อมกันทั้งสองหน้าเลย
> จึงใช้ **Insert** (อยู่ชิดซ้าย numpad มือเดียวกดถึง และ VALORANT ไม่ได้ผูกปุ่มนี้ไว้) —
> เปลี่ยนเป็นปุ่มอื่นได้ที่ `hotkeys: locate:` ใน `config.yaml` (ใช้ชื่อเช่น `delete`, `home`,
> `end`, `page up`, `f9`, `mouse4`)

## ตั้งค่า (`config.yaml`)

**ปรับจากหน้าเว็บได้แล้ว** — เปิด "จัดการคลังไลน์อัพ (เว็บ)" → แท็บ **ตั้งค่า** ปรับแล้วบันทึกเลย:

- **โหมดตามตัว (F9):** อ่านชื่อโซนตรงกันกี่ครั้งถึงจะขยับ (ค่าเดิม 2 — ตั้ง 1 = ขยับทันที), อ่านจอทุกกี่มิลลิวินาที,
  เดินออกแล้วตามต่อเอง, เปิดโปรแกรมมาแล้วตามตัวเลย
- **เทียบชื่อโซน:** ต้องคล้ายแค่ไหนถึงยอมรับ (ค่าเดิม 0.6) และต้องนำชื่ออันดับ 2 เท่าไหร่ (กันจับสลับ A/B)
- **หน้าแผนที่:** เรียงเลขหมุดจากใกล้สุด, หมุดหน้าอื่นเป็นจุดจาง, ขนาดวงโซน
- **หน้าต่าง:** จอที่ใช้, อยู่บนสุด, ชื่อไฟล์บนรูป ฯลฯ (ต้องเปิดโปรแกรมหลักใหม่)

ช่องที่ติดป้าย **มีผลทันที** โปรแกรมหลักใช้ค่าใหม่เองระหว่างเปิดอยู่ ไม่ต้องปิดเปิด · ด้านบนมีแถบ **ดูสด**
บอกว่าโหมดตามตัวรอบล่าสุดอ่านจอได้คำว่าอะไร จับคู่ได้โซนไหน/เฉียดชื่อไหนกี่คะแนน และทำไมแผนที่ขยับ
หรือไม่ขยับ — ใช้ตัดสินได้เลยว่าควรปรับ "จำนวนครั้ง" หรือ "เกณฑ์ความคล้าย"

ค่าที่ปรับเก็บใน `settings.json` (ข้างๆ exe) ทับค่าใน `config.yaml` · บิ้วใหม่ไม่หาย · ↺ = กลับไปใช้ค่าใน config.yaml

```yaml
display:
  monitor: 1 # 1 = LG ULTRAWIDE (จอดู), 2 = AOC (จอเล่นเกม)
  fullscreen: false # false = ไร้ขอบเต็มจอ แต่ลากย้ายจอได้
  max_images: 0 # 0 = โชว์ทุกรูปในกลุ่ม
  show_labels: false # ถ้าอยากได้รูปล้วนๆ ไม่มีชื่อทับ
  equal_size: true # ทุกรูปขนาดเท่ากัน / false = รูปแรกใหญ่กว่า
  start_on_map: true # เปิดโปรแกรมมาที่หน้าแผนที่เลย / false = เปิดมาที่กริดรูปแบบเดิม
```

แมพและฝั่งล่าสุดถูกจำไว้ที่ `last-view.json` เปิดโปรแกรมใหม่ก็อยู่ที่เดิม

ไฟล์เดียวกันยังนับด้วยว่าซูมดูรูปไหนไปกี่ครั้ง (นับตอนกด **Numpad 5** เท่านั้น)
แล้วดันรูปที่ใช้บ่อยขึ้นมาไว้ต้นกลุ่มของจุดนั้น — ยิ่งเล่นยิ่งไม่ต้องกด 4/6 หา
อยากล้างค่าให้กลับไปเรียงตามชื่อไฟล์ ก็ลบ `last-view.json` ทิ้ง

## บิ้วเป็น exe (เครื่องปลายทางไม่ต้องมี Python)

```bash
.venv\Scripts\python.exe tools\build_exe.py
```

ได้ `dist/LineupMaster/` ขนาดราว **160 MB** (ไม่นับคลังรูป) ก๊อปทั้งโฟลเดอร์ไปวางเครื่องไหน
ก็รันได้เลย ไม่ต้องลง Python ไม่ต้องรัน `setup.bat`

> **ปิด LineupMaster ให้หมดก่อนบิ้ว** (ทั้งโปรแกรมหลักและเครื่องมือทุกตัว) — ตัวบิ้วเช็คให้แล้ว
> ถ้ายังเปิดค้างอยู่จะไม่ยอมเริ่มและไม่แตะ `dist/` เลย เพราะ PyInstaller ลบ `dist/LineupMaster`
> ทิ้งทั้งโฟลเดอร์ก่อนสร้างใหม่ ถ้ามีโปรแกรมเปิดค้างมันจะล็อก `qwindows.dll` ไว้ ทำให้ลบได้แค่
> บางส่วนแล้วล้มกลางทาง — **ของที่ลบไปก่อนถึงไฟล์ที่ล็อกหายจริง** (เคยทำ `assets/maps` หายเกลี้ยง
> จนแผนที่ในทุกเครื่องมือหายไปหมดมาแล้ว) ถ้าเกิดล้มกลางทางจริง ตัวบิ้วจะเอา config/assets กลับ
> เข้า `dist/` ให้เองก่อนจบ ของเดิมจึงยังใช้ต่อได้

**ทางเข้าเดียว: `LineupMaster.exe`** → หน้าเข้าโปรแกรม (ไม่มีไฟล์ลัด .lnk แล้ว)

| ในหน้าเข้าโปรแกรม | ไปไหน |
| --- | --- |
| เข้าโปรแกรม | overlay บนจอที่สอง (ข้ามหน้านี้ได้ด้วย `LineupMaster.exe --overlay`) |
| คลังของฉัน / คอมมูนิตี้ / ตั้งค่า / การ์ดตัวเลข | หน้าจัดการ (เว็บ) ตรงหน้านั้น |
| เพิ่มไลน์อัพ | เพิ่มรูปเข้าคลัง (เว็บ) · ต่อรูปหลายขั้นเป็นใบเดียว (`compose`) |
| ช่อง F9 | เปิด/ปิดตามตัวตอนเริ่ม · ตั้งกรอบแคปชื่อโซน (`capture-region`) |
| ช่องจอ | เลือกจอที่ overlay ขึ้น |

**เครื่องมือของคนดูแล** (ใช้ตอนเกมเพิ่มแมพใหม่ ไม่ได้อยู่ในหน้าเข้าโปรแกรม) เรียกด้วยคำสั่งย่อย:
`LineupMaster.exe maps` · `callouts` · `callout-reference` · `place-callouts` · `auto-callouts`
และของเดิมที่หน้าเว็บทำแทนแล้ว: `manage` (หน้าจัดการ Qt แบบเดิม) · `pin` (จิ้มหมุด Qt)

**เป็น exe ตัวเดียวที่แยกงานด้วยคำสั่งย่อย** ไม่ได้บิ้วแยกหลายตัว เพราะ PySide6 ใหญ่มาก
(คำสั่งย่อยพวกนี้ใช้ตอนรันจากซอร์สได้ด้วย เช่น `python -m lineupmaster compose`)

### ต้องย้ายข้อมูลเข้าไปเอง

ตัวบิ้ว**ไม่ก๊อป `lineups/` ให้** เพราะคลังรูปหนักหลายร้อยเมกะไบต์ ถ้าก๊อปจะกลายเป็นสองชุด
แล้วเผลอแก้คนละที่จนข้อมูลเพี้ยน — ให้**ย้าย** `lineups/`, `positions.json`,
`last-view.json` เข้าไปวางในโฟลเดอร์นั้นเอง (หรือใช้ `--with-data` ถ้าจะเอาไปทั้งชุดใส่ USB)

ข้อมูลทั้งหมดอยู่**ข้างนอก** exe เสมอ ไม่ได้ฝังเข้าไปข้างใน จะได้แก้รูป/แก้ config ได้
โดยไม่ต้องบิ้วใหม่ (ดู `src/lineupmaster/paths.py`)

### เรื่อง antivirus

โปรแกรมนี้ดักปุ่มคีย์บอร์ดระดับ OS (numpad) พอถูกแพ็กด้วย PyInstaller จะเข้าลักษณะเดียวกับ
keylogger ทำให้ AV บางตัวเตือนได้ — **ทดสอบกับ Windows Defender แล้วผ่าน ไม่เจออะไร**
แต่ถ้าเครื่องอื่นเตือน ต้องใส่ข้อยกเว้นให้โฟลเดอร์เอง (ตัวบิ้วปิด UPX ไว้แล้วเพราะยิ่งบีบยิ่งโดนจับ)

ถ้าไม่อยากยุ่งกับเรื่องนี้เลย ใช้ `setup.bat` แทนได้ — รันผ่าน `python.exe` ที่ Windows
รู้จักอยู่แล้ว แทบไม่เจอปัญหา AV

## อัปเดตโปรแกรม / ย้ายของระหว่างสองเครื่อง (รวมคลัง)

ใช้เมื่อ**ทั้งสองเครื่องเพิ่มไลน์อัพของตัวเอง** แล้วจะเอาเวอร์ชันใหม่ (หรือของจากอีกเครื่อง) ผ่าน
Google Drive มาลง — **อย่าแตกโฟลเดอร์ใหม่ทับของเดิม** ของที่เครื่องนี้เพิ่มเองจะหายหมด

1. โหลดโฟลเดอร์ `LineupMaster` จาก Drive ไปวาง**ที่ใหม่** เช่น `Desktop\LineupMaster-ใหม่`
2. เปิด **"จัดการคลังไลน์อัพ (เว็บ)"** จากโฟลเดอร์ใหม่ → กดปุ่ม **รวมคลัง…** มุมขวาบน
3. เลือก**โฟลเดอร์เก่า**ของเครื่องนี้ (โปรแกรมหาโฟลเดอร์แถว Desktop / Downloads ให้เอง หรือวาง path ก็ได้)
4. ดูสรุป — ติ๊กเฉพาะรายการ "ไม่แน่ใจ" / "ขัดกัน" ที่อยากเปลี่ยนจากค่าเริ่มต้น แล้วกด **รวมเลย**
5. ใช้โฟลเดอร์ใหม่ต่อได้เลย · โฟลเดอร์เก่าไม่ถูกแตะ เก็บไว้เป็นสำรองจนแน่ใจแล้วค่อยลบ
6. อยากให้อีกเครื่องได้ของของเครื่องนี้ด้วย → อัปโหลดโฟลเดอร์ใหม่ขึ้น Drive แล้วที่เครื่องนั้นทำแบบเดียวกัน

**รวมอะไรบ้าง:** รูป (พร้อมโน้ต/gif) · หมุด · สกิล/แท็ก/⭐/จำนวนครั้งที่ซ้อม · ป้ายชื่อโซน ·
รายการ "เอามาแล้ว" ของหน้าหาไลน์อัพ · สถิติใช้บ่อย

**กติกา**

- ใบที่ลบ/เปลี่ยนชื่อ/ย้ายผ่านโปรแกรม ถูกจดไว้ใน `changes.json` — รวมแล้ว**ไม่ฟื้นของที่ตั้งใจลบ**
  และเปลี่ยนชื่อตามอีกเครื่องให้เอง · **ลบผ่านหน้าจัดการคลังเสมอ** — ที่ลบด้วยมือใน Explorer
  โปรแกรมไม่รู้ รูปนั้นจะกลับมาตอนรวม (ถ้ายังเหลือสำเนาใน `.trash` จะขึ้นเป็นรายการ "ไม่แน่ใจ" ให้ติ๊กเอง)
- โปรแกรมจำรูปจาก**เนื้อไฟล์** ไม่ใช่แค่ชื่อ — เปลี่ยนชื่อไปคนละแบบก็ยังรู้ว่าเป็นใบเดียวกัน
- รูป (หรือโน้ต/gif) ชื่อซ้ำแต่เนื้อต่างกัน = "ขัดกัน" ค่าเริ่มต้น**เอาอันที่แก้ล่าสุด** (ดูจากเวลาแก้ไฟล์
  — อันเก่าเข้า `.trash`) มีรูปย่อสองฝั่งให้ดูเทียบ เปลี่ยนเป็น "เก็บทั้งคู่" รายใบได้ · ถ้าเวลาไฟล์ของ
  โฟลเดอร์ไหนดูเพี้ยน (เช่นแตก zip ที่โหลดจาก Drive แล้วทุกไฟล์ได้เวลาเดียวกันหมด) โปรแกรมจะเตือน
  แล้วตั้งต้นที่**เก็บของที่นี่**แทน ให้ดูรูปย่อแล้วเลือกเอง
- หมุด/สกิล/ป้ายชื่อโซนที่ไม่ตรงกัน ค่าเริ่มต้น**เก็บของโฟลเดอร์ที่เปิดอยู่** (ไม่มีเวลาแก้ไขรายรายการให้เทียบ)
- รวมแบบ "บวกกัน" — หมุด/แท็ก/⭐ ที่เอาออกบนเครื่องหนึ่ง จะกลับมาถ้าอีกเครื่องยังมีอยู่ ต้องเอาออกซ้ำหลังรวม
- **ปิดโปรแกรมหลักก่อนกดรวม** ไม่งั้นตอนปิดมันจะเขียนแมพล่าสุด/สถิติใช้บ่อยทับของที่รวมมา
- มีรายการไหนทำไม่สำเร็จ (เช่นไฟล์ถูกเปิดค้างอยู่) หน้าสรุปจะบอก — แก้สาเหตุแล้วกดรวมใหม่ได้เลย
- กรอบแคปชื่อโซน (`capture.json`) แมพล่าสุด และ `config.yaml` (จอที่ใช้ ปุ่มลัด) เป็นของแต่ละเครื่อง —
  เอาจากโฟลเดอร์ที่เคยเปิดบนเครื่องนี้ให้เอง (เปลี่ยนได้ในหน้าสรุป) · **ครั้งแรกหลังอัปเดตเป็นเวอร์ชันนี้**
  โฟลเดอร์ยังไม่รู้ว่าเคยเปิดบนเครื่องไหน ค่าเริ่มต้นจะเอาของโฟลเดอร์ที่เลือก — ดูชื่อเครื่องในหน้าสรุปก่อนกดรวม
- **ไม่ลบอะไรถาวร** ของที่ถูกแทน/ลบ และ json ก่อนรวม อยู่ใน `.trash/<เวลา>-merge/` ย้อนกลับเองได้
- รวมเสร็จแล้วถ้าเปิดโปรแกรมหลักค้างไว้ ปิดแล้วเปิดใหม่

## ย้ายไปเครื่องอื่น

ก๊อปทั้งโฟลเดอร์ไปได้เลย **ยกเว้น `.venv/`** แล้วที่เครื่องใหม่ดับเบิลคลิก:

```
setup.bat
```

ครั้งเดียวจบ — มันจะหา Python ในเครื่อง สร้าง `.venv` ใหม่ แล้วลงแพ็กเกจให้

### ทำไมต้องทำแบบนี้

`.venv/` **ย้ายข้ามเครื่องไม่ได้** เพราะข้างในฝัง path เต็มของ Python เครื่องเดิมไว้
(เปิด `.venv/pyvenv.cfg` ดูได้) พอเอาไปเปิดในเครื่องที่ชื่อผู้ใช้ไม่เหมือนกัน มันจะฟ้องว่า:

```
did not find executable at 'C:\Users\PC\AppData\Local\Python\...\python.exe'
```

อ่านเผินๆ เหมือนโปรแกรมเช็คชื่อเครื่อง แต่จริงๆ คือ **path เก่าที่ค้างอยู่ในไฟล์ตั้งค่าของ
`.venv`** เฉยๆ ไม่มีการเช็คชื่อเครื่องที่ไหนในโค้ดเลย

`run.bat` ตรวจให้แล้วว่า `.venv` ใช้ได้จริงไหมก่อนเปิด ถ้าไม่ได้จะบอกให้ไปรัน `setup.bat`
ส่วน `setup.bat` ถ้าเจอ `.venv` ที่ก๊อปมา จะบอกว่ามันชี้ไป path ไหนแล้วถามก่อนลบสร้างใหม่
(`.venv` เป็นแค่ที่เก็บแพ็กเกจ **ไม่มีรูปไลน์อัพหรือหมุดอยู่ข้างใน**)

### ข้อมูลของคุณอยู่ไฟล์ไหนบ้าง

**5 ไฟล์/โฟลเดอร์แรกอยู่ใน `dist/LineupMaster/` และไม่เข้า git เลย** — เก็บผ่าน Google Drive
แทน (อัปโหลด/ดาวน์โหลดเอง หรือตั้งซิงก์ต่อเนื่องก็ได้ ดูหัวข้อ
[เริ่มจากศูนย์](#เริ่มจากศูนย์-โคลนดึงโค้ดมาใหม่)) ถ้าย้ายเครื่องแบบก๊อปทั้งโฟลเดอร์โปรเจกต์เอง
(ไม่ผ่าน Drive) ต้องก๊อปพวกนี้ไปด้วยเองถึงจะได้
ของครบ:

| ไฟล์/โฟลเดอร์                      | เก็บอะไร                                                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `dist/LineupMaster/lineups/`       | รูปไลน์อัพทั้งหมด + gif + โน้ต                                                                              |
| `dist/LineupMaster/positions.json` | หมุดบนแผนที่                                                                                                |
| `dist/LineupMaster/callouts.json`  | ป้ายชื่อโซนที่วางตำแหน่งไว้ (ดูหัวข้อ [ป้ายชื่อโซน](#ป้ายชื่อโซน-เทียบกับที่เกมบอกบนจอ))                    |
| `dist/LineupMaster/meta.json`      | สกิล / ⭐ ไม้ตาย / แท็กสถานการณ์ / จำนวนครั้งที่ซ้อม ของแต่ละรูป                                            |
| `dist/LineupMaster/capture.json`   | กรอบบนจอเกมที่ปุ่ม **Insert** จะแคปมาอ่าน (ไม่มีไฟล์นี้ = ใช้ค่าเริ่มต้น มุมซ้ายบน)                         |
| `dist/LineupMaster/last-view.json` | แมพ/ฝั่งล่าสุด + สถิติรูปที่ใช้บ่อย (ไม่ได้มากับ Drive/git ก็ได้ สร้างใหม่เองอัตโนมัติ)                     |
| `config.yaml`, `aliases.yaml`      | การตั้งค่าและคำพ้อง (อยู่ที่ root ของโปรเจกต์ — **มากับ git**)                                              |
| `assets/maps/`                     | รูปแผนที่ (อยู่ที่ root — **มากับ git** ไม่ก๊อปก็ได้ รัน `fetch_maps.py` โหลดใหม่)                          |
| `assets/callout_reference/`        | รูปอ้างอิง tracker.gg (อยู่ที่ root — **มากับ git** ไม่ก๊อปก็ได้ รัน `fetch_callout_reference.py` โหลดใหม่) |

> **หมายเหตุสำหรับคนแก้โค้ด**: ไฟล์ `.bat` ต้องเป็น ASCII ล้วน ห้ามใส่ภาษาไทยในบรรทัดที่
> ต้องรัน (เช่น `echo`) เพราะ cmd.exe อ่านไฟล์ `.bat` ด้วย codepage ของระบบ ไม่ใช่ UTF-8
> ตัวอักษรไทยจะทำให้ตัวแปลคำสั่งเพี้ยนจนรันคำสั่งผิดตัวได้ — ข้อความไทยทั้งหมดอยู่ใน
> `tools/setup.py` แทน
